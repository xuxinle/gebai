feat(bpy): 真实资产 —— 机械腕表轮系（齿轮建出来了）

用 bpy 写了一个真实资产：8 个按模数生成的齿轮（齿形 + 轮辐窗口 + 轴孔），
按啮合中心距布局。这是 bpy 路线价值的最终检验——机制通不等于造得出东西。

判据 7/7（`tools/bpy_watch_probe`），出图 `bpy_watch_render.png`。

## 资产内容

| 齿轮 | 齿数 | 三角形 | 材质 |
|---|---|---|---|
| barrel_wheel | 42 | 2204 | 黄铜 |
| center_wheel | 26 | ~1400 | 黄铜 |
| third_wheel | 18 | ~1000 | 金 |
| fourth_wheel | 14 | ~860 | 金 |
| escape_wheel | 15 | ~900 | 蓝钢 |
| 3 个惰轮 | 12/10/16 | 860+ | 黄铜/紫铜 |

几何契约与 three.js 版一致：分度圆 = 模数 × 齿数，中心距 = m(z1+z2)/2，
齿相位按 `2π/z` 均分并对齐齿槽。

## 这轮抓到的两个大坑

### 1. MINIMUM 档没有 `max` / `min`

`max` 是 Python 最常用的内建之一，而 MINIMUM 档剪掉了它。症状：

    NameError: name not defined

**没有名字**（MINIMUM 档连异常参数格式化也剪了）。于是一个 400 行的齿轮
脚本因为 `max(bore * hub_scale, root_radius * 0.26)` 整个建不出来。

定位过程（花了很久）：
1. 先怀疑语法/名字拼错 → 用真 CPython 跑（新写的 `tools/bpy_script_check.py`）
   → 完全通过，排除
2. 逐行截断二分 → 卡在"切点落在 docstring 里"，三轮都没修准
3. 最后用**逐名 `eval` 探测**（把 bpy 相关名字列出来一个个试）才定位到 `max`

顺带查出还缺 `reversed` / `enumerate` / `filter` / `set` / `frozenset`。
全部打开（加起来几 KB），并要求 `python_features_probe` 逐条验（现 41 项）。

### 2. GC 根扫描：不能手搬栈

之前 `gc_collect` 里手写：

    gc_collect_root((void**)low, bytes / sizeof(void*));

小场景正常（根本不触发 GC），真实资产立刻崩：

    Assertion failed: ATB_GET_KIND(area, block) == AT_HEAD, gc.c:914

那行在 `gc_free` 里，看起来像"GC 实现有 bug"。根因是 `gc_collect_root` 的
契约要求**精确的指针数组**，而栈区间里混着非指针数据 —— GC 把某些整数当指针
误标、又把已释放的块当活物，最终把链表结构弄坏。

正解：用上游 `ports/unix/gccollect.c` 里那一行 `gc_helper_collect_regs_and_stack()`
（它同时扫**寄存器 + 栈**，用 setjmp 把寄存器现场落到栈上）。把
`shared/runtime/gchelper_generic.c` 纳入 third_party。

> 教训：**不要手搓栈扫描**。上游有专门的 helper，而"哪些内存是根"这件事
> 的边界比想象中难。

## 另外两处调整

- **堆 16 MB → 64 MB**：8 齿轮场景撞上堆顶。而 MicroPython GC 分配失败时
  **直接 assert 而不是抛 MemoryError**，所以留足余量比"刚好够"安全
- 相机对象被当 mesh 抽取 → 加 `isinstance(mesh, Mesh)` 判型，消掉假警告

## 新增诊断工具

| 工具 | 用途 |
|---|---|
| `tools/st_py` | 跑一个 .py 文件并打印 result/错误（排查时的 `python` 替代品） |
| `tools/bpy_script_check.py` | 用**真 CPython** 跑脚本（bpy 打桩），语法/名字问题一步到位 |
| `tools/python_features_probe` | 41 项 Python 特性逐条探测 |

前两个是这轮"找 `max`"的实际产物：MINIMUM 档下"能力缺失"与"我写错了"的
报错长得一模一样，必须有工具把两者分开。
