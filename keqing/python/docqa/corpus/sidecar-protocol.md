# 边车协议 v1

多语言子代理边车协议：宿主与驱动进程通过 stdin/stdout 管道按行交换 NDJSON。
每个请求分配自增 id，驱动按 id 应答；超时由宿主侧控制（默认 120 秒，
tool.call 可按调用参数延长）。进程意外退出由宿主自动重启（崩溃自愈，
在途请求重发一次）；连续快速退出 3 次放弃自动重启，防抖动风暴。

操作序列：init 上报名称与协议版本（须与 manifest 一致，不一致拒绝注册）→
tools.list 上报工具清单（裸名 + JSON Schema 原样透传给模型）→ tool.call
执行工具并返回 output 文本与可选 data 结构化输出。
