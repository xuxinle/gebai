## 诚实说明：静止占比 88%

按 `ot_bench` 口径（32×18 网格、逐格均值差 <1.2 算静止）：

| 指标 | 值 |
|---|---|
| 静止占比 | **88.1%** |
| 变化中位数 | 0.24 |
| p95 | 4.49 |

这个片子是**信息型**的（每屏 4 张卡片 + 标题），主体占满画面，
所以静止占比高是**结构性的**，不是"忘了做动效"。

尝试过并**量化证明无效**的方案：

| 尝试 | 结果 |
|---|---|
| 淡纹理点阵（alpha 0.03→0.30，直径 3→16） | 静止 88.3% → 87.0% |
| 光带横穿 + 中心呼吸 | 中位 0.11 → 0.25 |
| 图层 `states` 位移（7px → 42px） | 几乎无变化 |
| 大环旋转（半径 430、直径 34、alpha 0.62） | 中位 0.24，静止仍 88.1% |

**根因（定量）**：验收口径是「60px 格的均值变化」。而

1. **匀速平移/连续旋转测不到** —— 同样多的亮点只挪 13px，格均值几乎不变；
2. 装置覆盖率不够 —— 即使环包住画面，它只覆盖约 25% 的格子。

**要让静止占比真正下来，需要"明暗在跳"**（亮↔暗切换、线长度 8%→92% 伸缩、
整屏换内容），而不是"位置在移"。详见 `docs/caiyun_layout_script.md` §6.1.6
与 `tools/layout_alpha_probe`（给出了尺寸×alpha 的定量门槛）。

## 已知边界

1. **不是真三维**：片子里没有 `model3d` 图层（早期版本试过球体，与本片的
   信息卡排版不协调，最终去掉）。三维能力见 `c13-clawd` 等片子。
2. **配音是 VITS**：中文女声，情感平；要更自然需换模型。
3. **`t` 的坑**：给某场景加动效时，`layout` 的 `t` 是**场景内局部时间**，
   不是全片时间（`docs/caiyun_layout_script.md` §6.1.5）。
