# 消费者（改这里 = 全部生效，改别处 = 口径分家的下一次事故）：
#   ① bootstrap.ps1   —— Windows 自举（鸡生蛋入口，编 st 本身；解析见其 Read-LinkLibs 段）
#   ② bootstrap.sh    —— POSIX 自举（同上）

#
# 为何收成一份文件：这份清单曾散布在 5 处（自举×2 / 框架清单 / 交叉 toolchains×2 /
# 独立工程默认表），历史上漏过三次（dbghelp×2、secur32×1），每次的现象都是
# 「报错指向源码的 undefined reference」，排查方向被带偏。见 docs/PITFALLS.md。

# 各项的来源（为什么需要它）：
#   ws2_32      winsock（src/core/platform_net.cpp、src/net/*）

#   psapi       进程/模块枚举（崩溃报告与资源诊断）
#   secur32     Schannel TLS 的 SSPI 系（src/net/platform_tls_schannel.cpp）
#   winpthread  MinGW 的 std::thread 运行库（C++20 <thread> 在 winpthreads 上）
