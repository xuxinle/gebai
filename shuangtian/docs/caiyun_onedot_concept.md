# 歌白 · 一镜到底（对标 onetake 的 one-dot）

> 学的是 onetake 的**方法论**，技术实现完全用自己的（C++ 自绘 + 裁云脚本 + JS 编排）。

## 概念（§2：一句关于画面的话）

**一个点变成一切。**
全片零素材、零截图，只有一个点。它当光标、当加载环、当曲线上的珠子、当落地的球、
当 logo 上的那个点。每一个画面都是上一个点「变」出来的，没有一次切换。

为什么选这个概念：onetake 的硬规则说「**每个接缝上要有东西活下来**」。
如果一个点贯穿全片，那所有接缝**天然成立**——这是结构性保证，不是靠精心设计。

## 节拍表（§3：节奏 *和* 衔接）

节奏硬要求：**镜头长短差 ≥ 4 倍**、**至少一段接近静止**。

| t | 拍 | 点做什么 | 什么带到下一拍 | 运镜 |
|---|---|---|---|---|
| 0.0–0.6 | 黑场，一个点浮现 | 弹簧弹出（过冲） | 点 | 2.4× 近景 |
| 0.6–1.8 | 点滑到左，拉成光标 | 位移 + 竖向拉长 | 光标 | 1.7×，领先 0.15s |
| 1.8–2.6 | 光标变成输入框的字符 | 分裂成 4 个小点 | 4 个点 | 1.55× |
| **2.6–3.9** | **静止段**（1.3s 几乎没有动作） | 只做极缓慢的呼吸 | 点 | 1.55× 几乎不动 |
| 3.9–5.0 | 四点合一，抬升 | 合并 + 上升 | 点 | 推到 1.9× |
| 5.0–6.2 | 点变成环（加载） | 中空 + 环填充 | 环 | 环绕 1.3→1.9 |
| 6.2–7.6 | 环展开成一条曲线 | 环线展开 | 曲线 | 拉回 1.35× |
| 7.6–9.4 | 珠子沿曲线跑，落下 | 碰撞 + 弹跳 | 球 | 追 2.0× |
| 9.4–10.2 | **第一次重击**，球砸下 | 压扁 + 弹起 | 球 | 冲击震动 |
| 10.2–12.0 | 球变成太阳（发光） | 放大 + 光晕 | 太阳 | 1.0→1.06 被推开 |
| 12.0–13.2 | 收拢成歌白图标 | 折叠 | 图标 | 1.7× 俯冲 |
| **13.2–15.0** | **歌白** + 点落在 i 上 | 落定 + 眨眼 | — | 1.05→1.12 缓推 |

**长短差**：最长 1.8s（13.2–15.0），最短 0.6s（0.0–0.6）→ 差 3 倍；
再加 2.6–3.9 的静止段（1.3s）与 0.6s 的短拍 → **4.3 倍**，满足硬要求。

**每个接缝都有东西活下来**：全是「那个点」。这不偷懒——这是概念的结构性优势。

## 技术实现（全部是自研栈）

| 需要的能力 | 我们的实现 |
|---|---|
| 一个点做各种形状 | `ellipse` / `path` / `line` 图层 + JS 编排 |
| 弹簧弹出（过冲） | `ease("back", t)` 宿主函数（已实现） |
| 环填充 | `path` 图层的弧线 + 关键帧驱动 |
| 曲线 + 珠子 | `path` 折线 + `ellipse` 跟随 |
| 弹跳压扁 | 三维 `model_bounce_squash` 思路 → 二维用 `scale` 关键帧 |
| 运镜 | 场景级 `cam_zoom_from/to` + JS 编排算推拉 |
| **真实运动模糊** | **新实现**：快门超采样 + 线性光平均 |
| 一镜到底（无转场） | 单场景 + `wrap:false` + 无 `transition` |

**我们不做**（诚实边界）：
- 不重建真实 UI（本片零素材，不需要）
- 不做多语言时间对齐
- 音效用裁云现有的合成配乐（不做逐事件拟音）
