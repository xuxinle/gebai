# 文档可用性实测诊断（2026-10-09）

> 方法：以**本轮实现 louyue/caiyun 时的真实经历**为测试集——我在那一轮撞的坑，
> 正是"文档是否会在合适时机被用上"的天然样本。不做主观自评，只报实测。

## 一、本轮撞的坑，按"谁发现的"分类

### A 类：编译器当场报错的 API 误用（9 个）

`padding_all` 不是 BoxProps 字段 / `custom<Element>` 不可用 / `set_focus` 应为 `set_focused` /
`hit_test` 返回值冲突 / `make_circle` 是自由函数 / `resize` 返回 `Status`（nodiscard）/
`type_name` 特化要求 / designated initializer 字段序 / …

**结论：这类不需要文档。** 编译器给出的信息（含 "did you mean" 与符号名）比文档更快更准。
把它们写进文档是**负收益**（噪声会淹没真知识）。

### B 类：静默缺陷（编译器不报、跑起来也不报）——4 个

| 缺陷 | 为何危险 | 实际是靠什么发现的 |
|---|---|---|
| `Canvas::draw_canvas` 忽略 `DrawOptions::blend` | 八种混合模式静默退化成普通叠加，**界面完全看不出** | 导出 PNG 后逐像素比对 |
| 导出丢字幕（未传 `text_port`） | 预览有字幕、导出没有 | 推演"预览与导出该一致"时发现 |
| `apply_theme` 每帧覆盖 `style().background` | 色块一帧后变回主题色 | 控制通道读回属性 |
| 字幕片段不透明底盖掉下层轨道 | 多层合成看起来像没生效 | 看截图 |

**结论：这类**才**是文档该管的**，但发现它们靠的**不是文档**，而是"跑+看+比对"。
（这部分已进 `CONVENTIONS.md` §7 与 `DESIGN.md` §8.3.2 的"假绿测试"教训。）

### C 类：有真实往返代价、且**文档里已记**的坑——5 个，我 0 次查到

| 坑 | 文档里有没有 | 我查了吗 | 代价 |
|---|---|---|---|
| `st build --force` 不触发重编（要 `--force` + 删产物） | **有**（`BACKLOG.md` L857、L1529） | ❌ | 白跑 2 轮 |
| `build/bin/st` 与 `build/dev/bin/st` 不是同一产物 | 有（`DESIGN.md`） | ❌ | 一度误判 lint 规则没生效 |
| `copy2` 恢复会搬回旧 mtime | 有（`CONVENTIONS.md`） | ❌ | 逆向验证假绿 |
| Windows `subprocess` 默认 GBK 解码 | 有 | ❌ | 差点把工具问题当成代码问题 |
| `std::unique` 返回唯一段末尾（非重复项） | 有 | ❌ | 断言写反 |

**这张表是本次诊断的核心证据**：知识**在**，检索**断了**。

## 二、断点定位

### 断点 1：地图把「查坑」只导向 §8.2

`docs/README.md` 的意图索引写：

```
| **别重蹈覆辙** | `DESIGN.md` §8.2（真实缺陷，每条带现象/根因/修复）
                 + `docs/BACKLOG.md`「已完成」段 |
```

但**子Agent 提示词**对 BACKLOG 的导引是「开工前读 `BACKLOG.md` 的**相关段落**」，
而它的**标签身份是"待办台账"**——于是"查已完成段找历史坑"这个动作没有触发点。
C 类 5 条全部躺在已完成段里。

### 断点 2：230 KB 靠人翻不现实

`BACKLOG.md` = 3322 行 / 230 KB。两条重编知识分别在 **L857（前 26%）**与 **L1529（前 46%）**。
没有按主题的检索入口时，"知道它大概在里面"等于"找不到"。

### 断点 3：这些坑的**发生时机**与**存放位置**不匹配

C 类坑的共同点：**都在"操作流"上**（改完代码要重编、跑完测试要验二进制新鲜度、
写逆向验证脚本时要防 mtime）。而它们按**时间**堆在 BACKLOG 的已完成段里——
检索时人是按**场景**想的（"我现在刚改完代码"），不是按日期。

## 三、结论

1. **"好查"这一半：结构上已经好了**（19 份全收录、意图索引、路径机械可查），
   但**按主题检索一条具体知识**仍差——差距在 `BACKLOG.md` 的体量与组织方式上。
2. **"会在合适时机使用"这一半：失败**。且失败的形态很具体：
   **不是没记，是记的地方与"人何时会想起它"不匹配。**
3. 由此推出的方向：知识要按**发生场景**建检索面，而不是继续堆在大文件里按时间归档。
