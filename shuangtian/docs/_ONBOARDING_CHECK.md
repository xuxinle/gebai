# 接手文档检验记录（重启后，只读文件作答）

> 检验方法：服务重启后，**不依赖会话记忆**，只读 `docs/` 下的文件回答五道题。
> 这模拟的是"下一个会话/下一个人第一次接手"。

## 五道题与出处

### 1. `layout(t, …)` 里的 `t` 是什么时间？

**场景内局部时间**（从 0 开始、到本场景 `duration` 结束），**不是全片时间**。

出处：`docs/caiyun_ONBOARDING.md` §「三条最容易撞的」第 1 条；
完整取证在 `docs/PITFALLS.md`〔编排〕；实现细节在
`docs/caiyun_layout_script.md` §6.1.5。

### 2. `shapes` 的坐标是什么单位？相机参与吗？

**屏幕像素**（设计宽度 1920 基准）。`paint_script_shapes` 只乘
`画布宽/1920`，**相机/zoom 完全不参与**。另外**后 push 的在上面**（数组顺序叠）。

出处：`docs/caiyun_ONBOARDING.md` §「三条最容易撞的」第 2 条；
`docs/caiyun_layout_script.md` §6.2。

### 3. 一处改动后"画面变化了多少"，10 秒内量出来用什么工具？

```powershell
py scripts/probe_scene.py --script x.json --scene 2
```

它把除目标场景外的 duration 全置 0，只渲那一段，用与 `ot_bench`
**完全相同**的口径量。实测：全片 955 帧 ≈ 70s；单场景 160 帧 ≈ **5s**。

出处：`docs/caiyun_ONBOARDING.md` §「调功时要先跑单段探针」。

### 4. 60px 网格口径下，"整屏亮度变化 3 级"等于多少逐帧差？

**约等于 3.0** —— `dL` 与网格差是 **1:1** 关系。

出处：`docs/caiyun_layout_script.md` §6.1.8 第 ① 条
（表里那行 `整屏亮度变化 dL | — | = dL（1:1）`）。

> **检验时这一条只在 layout 脚本文档里，ONBOARDING 只有配方没有依据** ——
> 已补，见下方「检验后补的两个缺口」。

### 5. 片子静止占比 88%，按文档该先试什么手法？

**整屏亮度脉动**（dL 1:1，性价比最高）：一层覆盖全屏的半透明白，
alpha 在 0.006~0.032 间按 0.36s 周期起伏。实测把歌白片从 88.1% 打到 **62.8%**。

文档明确写了「在此之前调了 5 轮淡纹理点阵，只从 88.3% 到 87.0%——
**手法选错了，调参是白费**」。

出处：`docs/caiyun_ONBOARDING.md` §「最有效的手法：整屏亮度脉动」。

## 检验后补的两个缺口

| 缺口 | 补法 |
|---|---|
| 第 4 题的定量依据（dL 1:1）只在 layout 脚本文档，ONBOARDING 只有配方 | 已把 1:1 的依据与"另两条数值规律"的指针写进脉动那一节 |
| 没有一条「改完怎么知道真的生效了」的**可复制命令序列** | 已新增「一次完整操作（改 → 验执行 → 量变化 → 看观感）」四步，含每步失败判据 |

另外修了一处**会误导人的旧表述**：参考片表里原本写「歌白 30s …静止 88% 是结构性的」，
已改为「88%→**63%** 靠整屏脉动一刀下来」——旧写法会让新人以为 88% 无法改善而直接放弃。

## 一句话评价

**够用**（补完上述缺口后）。五道题现在都能在 `caiyun_ONBOARDING.md` 单独找到答案；
新增的「一次完整操作」我已按它**实际跑通**（`loaded=true count=91` → 单段 5s 出数，
静止 52.5% / p95 5.56）。

### 仍然不够的地方（诚实列出）

1. **没有参考片基线**：`_ref_*.mp4` 已不在本地，两个子会话都因此无法判定
   "过亮/静止是否优于参考"。新接手的人会撞同一面墙——建议把参考片纳入仓库。
2. **"观感好不好"仍无工具**：本轮两个子会话都独立提到同一件事——
   没有工具能把**单帧观感**与**全片指标**解耦。指标现在能秒级量了，
   但"这一帧好不好看"仍靠抽帧加肉眼，而抽帧得先有片子。
3. **"结构性太平"的片子仍无定论**：c06-pith 的 p95 与"克制终端界面"的
   美术取向存在冲突——白点方案能达标但画面变雪花屏。这是需要人拍板的取舍，
   文档只能把它写清楚，不能代决定。
