# 剧本 · 歌白能力片「收编」

> 用途：**检验裁云的视频能力边界**，不参考已有歌白片子。
> 目标不是"讲清产品"，而是"把渲染器的每一类能力都推到台面上，看它能不能撑住"。

## 一、定位

| 项 | 内容 |
|---|---|
| 一句话定位 | 给懂技术的人看，看完记住：**旧世界的一切技术，都是可以收编的躯体** |
| 受众 | 开发者 / 技术决策者；他们在意"这东西真的能干活吗" |
| 使用场景 | 官网首屏 / 内部演示 |
| 时长与画幅 | 38.4 秒；16:9 1920×1080 30fps |
| 语言与声音 | 中文配音 7 句；配乐 calm / 96 BPM；**零音效**（默认策略） |

## 二、内容结构（能量曲线）

| 段 | 幕 | 作用 | 观众反应 | 时长 | 画面主体 |
|---|---|---|---|---|---|
| 1 | 收编 | 建立注意 | "这是什么？" | 4.6s | 210 个字块向中心塌缩 |
| 2 | 躯体 | 说清是什么 | "哦，是给智能一个身体" | 5.2s | 三维实体世界 + 逐字字标 |
| 3 | 工具面 | 给证据 | "它真的接得进东西" | 5.8s | 23 张工具卡错峰弹入 |
| 4 | 钻穿 | 抬升 | "能钻进去看" | 5.4s | 终端窗口 + 矢量钻穿 |
| 5 | 扩张 | 峰值 | "量级在这里" | 6.0s | 336 点阵尺度揭示 + 承接 |
| 6 | 回路 | 转折 | "它还会改自己" | 5.4s | 双环节点流动 |
| 7 | 字标 | 收尾 | 记住名字 | 6.0s | 粒子汇聚 + 大字落定 |

能量：低开（塌缩）→ 立传（三维）→ 爬升（卡片/钻穿）→ 峰值（点阵扩张）→ 回落（回路）→ 落定（字标）。

## 三、逐镜设计

| # | 时长 | 画面构成 | 文字（逐字） | 动效 | 采样帧 |
|---|---|---|---|---|---|
| 1 | 4.6s | 全屏 210 个字块沿径向向中心塌缩，中心亮核脉动 | 无（末段浮出「旧世界的一切技术」） | 径向收缩 expoInOut 0.12→2.45s；字块带切向旋转；2.35s 起淡出；3.0s 标题上浮 | 0.6 / 1.9 / 3.6 |
| 2 | 5.2s | 右半屏三维共享世界：地面 + 环 + 球 + 方块，左侧字标 | 「歌白」「GEBAI AGENT」 | 三层自转 8~11°/s、浮动 0.04；左竖线 0→100%；逐字上浮 stagger 0.06 | 5.4 / 7.2 / 9.0 |
| 3 | 5.8s | 6×4 网格 23 张工具卡，每张 1 标题 2 副行 | 「二十三种能力，一次装载」+ 计数 0→23 | 弹簧入场 ζ0.55/ω18，径向错峰 0→1.1s；落定后逐卡微起伏 3px | 10.3 / 11.6 / 14.6 |
| 4 | 5.4s | 居中终端窗口，6 行输出逐行淡入，扫描线上下走，光标闪 | `> agent_load` / `工具面并入` 等 6 行 | 相机**矢量钻穿** 1.0→1.85（锚 0.30,0.55，窗口 0.2–3.2s，expo_out）；扫描线 2.6s 一程 | 16.2 / 18.0 / 20.4 |
| 5 | 6.0s | 24×14=336 点阵，从微距 0.12 拉到全景 1.0 | 无 | scale 0.12→1.0（expoOut 0.2–3.2s）；逐点明暗波（波前随时间推进）；扫描带两趟；中心方块承接变形为全屏 | 21.5 / 23.6 / 26.4 |
| 6 | 5.4s | 双同心环，30 个节点沿环流动，中心双行字 | 「改自己，也走同一条回路」 | 节点角速度 0.55 rad/s；环脉冲 2.2s；中心字逐字上浮 | 27.6 / 29.4 / 31.8 |
| 7 | 6.0s | 120 个粒子从四周汇聚，中心大字 + 细线展开 | 「歌白」/「GEBAI AGENT」/ 页脚 | 汇聚 0.2–2.6s 然后消失；字标弹簧落定；3.0s 起静止（只留呼吸） | 33.0 / 34.4 / 37.6 |

**关键元素落定后留 ≥1s 静止**：幕 4 相机 3.2s 停住、幕 7 3.0s 起静止。

## 四、视觉规范（从产品自身取）

| 项 | 值 | 来源 |
|---|---|---|
| 强调色 | `#3B82F6` | 歌白 Web `base.css` 的 `--accent` |
| 背景 | `#08090D` → `#101724` | `--bg-inset #0d1117` / `--bg-elev #161a24` 同族 |
| 主文字 | `#EAF0FF` | `--text #e6e6e6` 略冷化（深底上更透） |
| 次文字 | `#9EC4FF` / `#6F86A6` | 同色相不同明度 |
| 字号层级 | 110 / 64 / 44 / 26 / 20 | 与产品 UI 同比例放大 |
| 圆角 | 14（卡片）/ 4（芯片） | 产品面板圆角 |
| 特效强度 | glow 0.25~0.8 / particles 30~90 / grain 600~1200 | 全部在克制表内 |

**跨风格硬规则**：深底呼吸用 `#FFFFFF` alpha 0.004~0.02（提亮），不用暗色。
