# 三维与连线（3d）

## 选型

| 要什么 | 用 | 是否声明式 |
|---|---|---|
| 把一份 three.js 场景渲进界面的一块区域（可鼠标交互） | `ThreeView` | **否**（C++ `new` 挂树） |
| 演示用的内置几何（立方体/球/…）快速搭一个三维视图 | `SceneView` | **否** |
| 给三维里的物体画文字标签与连线（屏幕空间） | `LabelOverlay` | **否** |
| 二维连线（流程图/节点图/思维导图/状态机/拓扑） | `Connector` | **是**（`ST_UI_COMPONENT` 已注册） |

三维三兄弟**不在注册表**的理由写在各自头末尾：无头环境下"按名建三维"没有意义，
它们由 C++ 直接 `new` 并挂树。所以 XML/JS 里写 `<ThreeView>` **不会**生效。

## ThreeView 四条要点

1. **真值是一份场景脚本**（JSON），组件只是渲染宿主——改画面改脚本，不要在渲染回调里改几何。
2. **相机是状态属性**（`distance`/`yaw`/`pitch`），可用 `reset_view`/`home`/`frame_scene` 动作摆位。
3. **拾取用属性面**：`picked`/`selected_name`；不要用屏幕坐标反推物体。
4. **两条渲染腿**：`backend` 属性告诉你当前走的哪条（软/硬）；断言像素时**两条腿分别验**（容差比对）。

## Connector 三条要点

- **坐标是本地坐标**（原点 = 自身 `bounds` 左上角）。给元素端点时组件内部会把绝对坐标换到同一套；
  自己算多边形时别再把原点加一次。
- **命中是沿线窄带**（`hit_tolerance`），不是整块 bounds——所以 `absolute` 铺满父级时
  **不会吃掉**下层按钮的点击。要"点线选中"就接 `on_line_event`。
- **虚线是路径层切段**：光栅层没有 dash（`StrokeStyle` 只有 cap/join），段数越多描边次数越多。

端点四种给法（优先级从高到低）：`set_source_fn`/`set_target_fn`（每次绘制现算）
→ `set_source`/`set_target(element, side)`（跟随元素、元素不可见时整条不画）
→ `set_points`（固定坐标）→ 什么都不设（用自身 bounds 的对角）。

## 坑

| 坑 | 说明 |
|---|---|
| 想用 XML 声明 `<ThreeView>` | 它没进注册表，标签会被如实报为 unknown |
| 在无头环境断言三维像素 | 软件腿可以；硬件腿要靠平台能力检测，`backend` 会告诉你实际走了哪条 |
| 把 `Connector` 铺满父级且不加 `absolute` | 会进 flex 流占位，把布局挤开 |
| 用屏幕坐标算三维点击 | 用组件 `picked`/`selected_name`，或用控制通道 `input.mouse` 走真实路径 |
