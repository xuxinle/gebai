# 浮层（overlay）

## 选型

| 情况 | 用 |
|---|---|
| 必须用户确认/填写后才能继续 | `Dialog`（模态、遮罩、按钮行） |
| 一闪而过的结果提示 | `Toast`（见反馈族） |
| 悬停解释 | `Tooltip`（见反馈族） |
| 持续存在的提示条 | `Banner`（见反馈族） |
| 下拉/弹出列表 | `SelectPanel`（见选择族） |

## 用法要点

- 模态期间输入应被遮罩吞掉（焦点不能跑到后面的控件上）；无头断言就查"焦点仍在对话框内"。
- 按钮行顺序：主操作在右（Windows 惯例），取消在左。
- 关闭方式要**三条都有**：按钮、`Esc`、点遮罩（或显式声明不允许点遮罩关，例如有未保存内容）。

## 坑

| 坑 | 说明 |
|---|---|
| 在对话框里改数据后直接关 | 用户以为已保存；关闭前要落盘或给出"未保存"分支 |
| 用 `Dialog` 承载长表单 | 它不滚动；长内容要包 `ScrollView` |
| 打开/关闭不标脏 | 遮罩与卡片是浮层，必须触发全量或对应区域重绘，否则残影 |
