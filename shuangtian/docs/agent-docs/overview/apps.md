# 应用（示例即靶场）

`apps/` 下每个都是可直接双击运行的桌面程序。它们的存在不是为了"演示"，而是**用真实应用检验框架**——
一个新能力若没有应用用到，就不知道它到底够不够用。

| 应用 | 职责面 | 主表面 | 检验什么 |
|---|---|---|---|
| `gallery` | 组件 / 设计系统 | 内置组件全集 | 组件库完整度、令牌一致性、DPI |
| `gbcode` | 文本 / 编辑器（全声明式） | `CodeEditor` | 声明式组装复杂应用；真实文件 / LSP / Git / 终端全链路 |
| `louyue` 镂月 | 像素 / 光栅创作 | 自绘画布 | `BlendMode`/`Surface` 合成、逐像素、PNG 往返、撤销栈 |
| `caiyun` 裁云 | 时间 / 动效 + AI 生成 | 导演脚本 → 成片管线 | 帧预算、续帧协议、擦洗/拖拽修剪、跨线程长任务 + 进度回 UI |
| `xiangqi` 相期 | 纯 XML + JS 通路 | `ui/main.xml` + `ui/app.js` | 零 C++ 界面代码也能成应用；改 XML/JS 保存即生效 |
| `gedou` 格斗 | 实时游戏 | 自绘骨架舞台 + 60Hz 逻辑帧 | 固定步长逻辑帧与渲染帧解耦、"按住/边沿"两种键语义、判定盒与骨架同源、同种子可复现 |
| `cefu` 册府 | 结构化知识库（由歌白子Agent 驱动） | 条目检索/整理 | 文本检索与界面协同 |
| `jianmu` 建木 | 三维建模与演示 | three.js 场景 + bpy 建模脚本 | 热重载实时预览、轨道相机、拾取高亮 |

## 交付形态（容易被忽略的两件事）

- **图标有三条独立链路**：`st.pkg` 的 `"icon"`（文件图标，构建期进 PE 资源）、
  `AppOptions::window_icon_png`（任务栏/Alt-Tab，运行期后端）、`svg_registry` + `TitleBar::set_icon`
  （自绘标题栏）。只配第一条 ⇒ **文件图标好看、任务栏空白**。
- **不弹控制台**：`"system": "gui"`（PE Subsystem=2）。工具链与探针**故意保持 console**（要能管道）。
  GUI 应用带参数从 cmd 启动时输出不会丢（入口会把 stdout 接回父控制台）。
