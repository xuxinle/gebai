# 概述：霜天是什么

**霜天是一个通用 C++23 桌面应用框架**，但它和常见 UI 框架有三处根本不同，
这三处决定了后面所有写法：

| 不同点 | 意味着什么 |
|---|---|
| **全自绘**（不用系统控件） | 界面长什么样由框架的画布决定，**像素可控**：截图就是真相，可以逐像素断言 |
| **无头模式是第一等公民** | 没有桌面（Linux 服务器、CI 容器）也能完整跑界面、截图、操作——这是"智能体能开发界面"的前提 |
| **控制通道是正式接口** | 程序可以被外部进程用 `tree`/`find`/`get`/`set`/`invoke`/`capture` 观察与操作，不靠模拟鼠标猜坐标 |

三者叠起来的效果：**改代码 → 构建 → 启动 → 截图 → 断言**可以全程无人值守闭环。

## 它能做什么（能力面）

- **界面**：74 个组件（按钮/表格/代码编辑器/终端/时间轴/三维视图…），一套设计令牌（含十套内置主题），
  响应式布局、动画、DPI 一等公民（逻辑/物理像素分离，支持非整数倍率与运行时切换）。
- **文本**：自研 TTF/OTF/CFF 字体解析与整形（CJK 回退、SC face 优选）、按物理尺寸栅格化 +
  字形缓存、软换行/省略；Markdown 解析 + 零依赖代码高亮（流式，面向大模型输出）。
- **渲染**：软件光栅器（扫描线覆盖率抗锯齿 + SIMD 快路径）为**唯一真相源**；
  GPU 合成为可选加速（无显卡时软件路径照常）；三维一条独立通路（软/硬件两条腿）。
- **平台**：Windows（Win32 + D3D11）、Linux（X11 / Wayland）、macOS。
- **构建**：自研包管理器与构建驱动 `stpm`（不依赖 CMake/Make），`st build/test/lint`，
  内容哈希增量、PCH、并行、lld。
- **可当库用**：`st_core` 库目标把九个与界面无关的模块单独打出来，可给无界面程序链。

## 它不做什么（明确的非目标）

- **不做通用 GUI 工具箱的等价物**：没有原生控件外观适配、不追求"和系统对话框一样"。
- **不做完整 Web 引擎**：`HtmlView` 只支持基础 CSS 子集、无 JS、不联网。
- **不做完整 ArkTS 方言**：声明式只做**形态兼容**（心智模型一致、迁移成本低），不是语法兼容。
- **不承诺 API 稳定**：这是产品代码库，公共接口会为能力与正确性让路（改动要同步文档与测试）。
