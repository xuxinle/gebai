# 坑位速查（场景索引）

每条只给**一句话 + 出处**。要完整根因与代价，按出处下钻——那里有实测数据。

## 判定类（最贵的一类）

| 坑 | 一句话 |
|---|---|
| 「绿」不代表起作用 | 它只证明"我查的那个东西当时在"；查之前先问：我查的是**行为、代码，还是字符串**？ |
| 零红没报分辨力 | N 轮全绿只说明失败率 p ≲ 3/N；报零红必须给轮数 + 对照条件 + 检出下限 |
| 回退是空操作 | `if (len < 0)` 这类恒假判断等于没回退，而全套仍绿 |
| 回退版编译不过 | 跑的是上一份二进制（假绿）；回退文本必须编译过 |
| 锚点会过期 / 只在注释里 | 消灭缺陷时同步改锚点；锚点要统计**代码行**命中，不能只看字符串在不在 |

## 刚改完代码要验证

| 坑 | 一句话 |
|---|---|
| `重编 0` ≠ 没编 | 先查 `.meta` 的内容哈希、再在产物里搜新字符串；两项都否才 `--force` |
| 三个"缓存"不是一回事 | 对象复用 / 链接跳过 / 一次性去重可以独立发生 |
| 产物路径有两套 | `build/bin/st`（自举）与 `build/dev/bin/st`（真产物） |
| `st build <target>` 不链测试二进制 | 改共享头（含尺寸的 `inline constexpr`）后只 `build`，运行期崩而编译期零告警 |
| 字符串搜到 ≠ 新二进制 | 决定性判据是行为（如 `st lint --rules` 能否列出新规则） |

## 量测类

| 坑 | 一句话 |
|---|---|
| 分层窗口截图是废的 | `WS_EX_LAYERED`/磨砂窗口用 `GetDC` 抓到的是重定向表面的黑，不是合成结果 |
| 被测量动作自己的耗时会计入读数 | 量"用户等了多久"要做减法拆开（卡在屏 − 动画占用） |
| `PrintWindow` 会修好你要看的瞬态 | 它会触发一次重绘；要抓启动黑屏得用桌面 `BitBlt` |
| 采样粒度要细于被测特征 | 稀疏采样会把瞬时问题测成持续问题 |

## 写界面

| 坑 | 一句话 |
|---|---|
| `pump_async` 与 `dirty()` 顺序反了 | 静默死锁：异步永不收敛 |
| 构建期存的元素指针跨帧用 | 重组销毁重建 ⇒ 悬垂 |
| `set_text` 当"更新文本"用 | 光标归零、撤销栈清空、视口回顶；要保位置走 `replace_text_keep_state` |
| `custom<T>` 塞子元素 | 必须 `custom_container<T>` |
| `BoxProps` 没有 `tone`；字段有初始化顺序 | 走 setter；报错按提示调顺序 |

## 画自绘 / 改光栅

| 坑 | 一句话 |
|---|---|
| 填充不隐式闭合子路径 | CJK 字形糊块 |
| 覆盖率当透明度用 | 带符号量⇒圆角/阴影/字形全失效 |
| 增量重绘的损坏区算漏 | 少刷一块的表现像"随机残影" |
| GPU 与软件的验收口径 | 容差比对，不是 bit-exact；顶点四边形要向外扩 1 像素（边界行丢墨的根因） |

## 跨平台

| 坑 | 一句话 |
|---|---|
| 系统 API 混进业务代码 | 只许出现在 `platform_*`，否则别的平台直接编不过 |
| 手拼路径 / `ifstream(std::string)` | Windows 按 ANSI 解释，中文路径必坏；一律经 `st::fs` |
| `long` 表示字节数 | Windows 上是 32 位 |
| 机械套用 `--toolchain=mingw` | Windows 宿主上原生工具链本就是 mingw64，是同一件事做第二遍 |

## 嵌外部窗口 / 与「异步重排」的东西对位

| 坑 | 一句话 |
|---|---|
| `SetParent` 后立刻量偏移 | 量到的是旧布局（实测 107，真值 0）；要逐帧短收敛，就位即停 |
| 「面积最大」当判据 | 浏览器进程里 D3D 层与真渲染视口面积几乎一样；只在 top 严格大于客户区顶边的候选里取 |
| 矩形变了就在同一帧读数 | 读到旧值 ⇒ 误判「已就位」 ⇒ 收敛永不启动；变化本身就触发收敛 |
| 同一条不变量写两遍 | `attached()` 看句柄、属性面看读数 ⇒ 没嵌入也报 `true`；机读通道会被自动化采信 |
| 嵌入内容的像素 | 不进 `framebuffer()`：要验「真的上屏」得从桌面 DC `BitBlt` 抓（先提前景） |
| 平台子窗口不认 `visible`/裁剪 | 切页后仍盖在别的页上、滚出视口不消失；要下发“可见矩形”（自身 ∩ `clip_children` 祖先） |
| 隐藏子树的 `arrange` 不再跑 | “靠布局回调收尾”的逻辑在隐藏时一次也不跑；走可见性广播（递归整子树） |
| 解除嵌入只还原样式 | 嵌入期把窗口上移了一个标题栏高度（为藏标题栏），不还原几何 ⇒ 变成顶层后那个上移量就是屏幕坐标：标题栏在屏外、拖不动（实测 `(0,-107)`、拖拽位移 0） |
| 嵌入前的矩形要在 `SetParent` 前记 | 之后 `GetWindowRect` 给的是相对宿主坐标，原值再也取不回来；`dismiss` 时只能猜 |
| 刚恢复的 `WS_CAPTION` 不落位就不认 | 不加 `SWP_FRAMECHANGED` 就不过 `WM_NCCALCSIZE`：样式回了、非客户区还是子窗口那套 |
