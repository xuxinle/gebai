# 剧本 · 裁云「一镜到底」能力展示（16 秒）

> 对标 [onetake](https://github.com/feitangyuan/onetake) 的 `onetake-launch-30s`：
> 每个画面都从上一个里长出来。本片的目标是**每个边界都有承接**（carry score ≥ 0.7）。

## 一、定位

| 项 | 内容 |
|---|---|
| 一句话定位 | 给**评估动效能力的人**看，看完记住**裁云的镜头之间不是切换，是长出来的** |
| 时长与画幅 | 16 秒；1920×1080（16:9） |
| 语言与声音 | 中文；无配音；**零音效**（默认策略） |

## 二、结构（能量曲线）

| 段 | 作用 | 观众反应 | 时长 | 画面主体 |
|---|---|---|---|---|
| 1 起 | 一个点出现 | 「这是什么？」 | 2.4s | 光标点 + 单词 |
| 2 承 | 点长成卡片 | 「哦，它在长」 | 2.6s | 卡片从点长开 |
| 3 转 | 卡片长成整页 | 「变成界面了」 | 3.0s | 卡片 → 全屏页面 |
| 4 承 | 页面收成一条线 | 「还能收回去」 | 2.8s | 页面 → 细线 |
| 5 合 | 线长成标志 | 「记住了」 | 3.0s | 线 → 字标 |
| 6 落 | 字标静止 | 呼吸 | 2.2s | 静止 + 微光 |

**关键**：段 1→2、2→3、3→4、4→5 都是**同一个元素在变形**，
不是两幕各自入场。段 6 是唯一允许的静止（rest 是节奏的一部分）。

## 三、逐镜设计（承接写在每一行里）

| # | 时长 | 画面 | 文字 | 承接（跨到下一幕的那个东西） |
|---|---|---|---|---|
| 1 | 2.4s | 中心一个小点，呼吸 | 点旁一行小字「材料」 | **点 → 卡片**：8% 小方块长成 36% 卡片，圆角 4→16 |
| 2 | 2.6s | 卡片占据中央，微浮 | 卡内「一镜到底」 | **卡片 → 页面**：36% → 100%，圆角 16→0 |
| 3 | 3.0s | 满屏页面，内部有网格 | 页内标题「每个画面从上一个里长出来」 | **页面 → 细线**：100% → 82%×1.2%，圆角 0→2 |
| 4 | 2.8s | 一条细线横在中央 | 线上方「不是切换」 | **细线 → 字标**：82%×1.2% → 52%×13%，圆角 2→8 |
| 5 | 3.0s | 字标「长出来」 | 无 | 无（终幕） |
| 6 | 2.2s | 字标静止 + 微光呼吸 | 副标「NIMBUS · 跨场承接」 | 无 |

## 四、视觉规范

| 项 | 值 |
|---|---|
| 强调色 | `#4d6bfe`（裁云品牌色） |
| 背景 | `#05070f` → `#0f1728`（深蓝黑） |
| 承接图元 | 填充 `#152238`、描边 `#4d6bfe` 3px、文字 `#9ec4ff` |
| 字号 | 主 92 / 副 34 / 卡内 44 |
| 特效 | glow 0.35 / grain 900（让静止段"安静而不冻结"） |

## 五、声音

| 类型 | 内容 |
|---|---|
| 配乐 | `calm`，BPM 92，gain 0.35（本片是"慢慢长开"，不要强节奏） |
| 音效 | **零音效**（默认策略） |

## 六、为什么能比肩 onetake

| 判据 | onetake 参考值 | 本片目标 |
|---|---|---|
| carry score | launch 0.83 / v3 0.75 / 接受下限 0.5 | **≥ 0.7**（5 个边界全部承接） |
| 承接手法 | morphRect / iris / zoomThrough / gather / seal | 用 `carry_out` 的矩形 morph（同 morphRect 语义） |
| 节奏 | 镜长 CV ≥ 0.25，≥25% 帧静止 | 镜长在 2.2~3.0 间变化；终幕静止 |
