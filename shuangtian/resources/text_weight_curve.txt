# 环境变量 `ST_TEXT_WEIGHT_CURVE` 可指向别的文件（对照实验用）。
#
# ══════════════════════════════════════════════════════════════
# 先读这一段：**霜天的字重跨字号本来就基本一致**
# ══════════════════════════════════════════════════════════════
#
# 用「过渡带均值」（排除满黑区与抗锯齿尾巴后的笔画实度）实测：
#
#     9px 0.416 · 13px 0.433 · 15px 0.437 · 22px 0.422 · 32px 0.421 · 40px 0.425
#     波动仅 5%。
#
# （早前用「平均覆盖率」量出 34.9% 的漂移，那个指标是**错的**——
#   大字号笔画宽、内部天然形成大片满黑，把平均值抬高了。那是几何必然、
#   正确的行为，不该被"纠正"。换指标后漂移就消失了。）
#
# 所以本表的定位不是"大幅纠正"，而是**给你一个连续、可调的旋钮**：
#   · 默认值接近恒等（γ≈1.0），对现状几乎无影响；
#   · 你想让某个字号段更黑/更淡，改对应行即可，中间自动插值、无跳变。
#
# ══════════════════════════════════════════════════════════════
# 为什么是"采样点 + 分段线性"，不是公式也不是分档
# ══════════════════════════════════════════════════════════════
#
#   · 公式（如 a+b*ln(px)）能拟合趋势，但没法精确压住某一档的偏差；
#   · 分档（<14 一档、>=14 另一档）在档位边界**跳变**——字号连续变化时会看到
#     "字突然变粗"，而且永远覆盖不全；
#   · 采样点 + 分段线性插值：哪档偏就在哪档补一个点，中间**连续无跳变**。
#
# ══════════════════════════════════════════════════════════════
# 字段与控制轴分工
# ══════════════════════════════════════════════════════════════
#
#   每行：`<物理字号px>  <gamma>  <contrast>  [备注]`
#
#   gamma    —— 覆盖率 gamma。**越小越黑**（加墨）。范围 [0.30, 4.00]。
#               映射：α' = 1 − (1−α)^(1/γ)
#   contrast —— S 曲线对比度，γ 之后施加：a' = a + (1−a)·c·a。范围 [0, 3]。
#
#   **两条轴分工，别混用**：
#     · gamma    管"笔画整体的实度"（单调可控，主旋钮）；
#     · contrast 管"满黑像素占比"（只抬中间调，对平均实度影响小）。
#
#   ⚠ 踩过的坑：让两者都去拉平"平均覆盖率"，会导致大字号的 gamma 被压到
#     0.30 下界仍降不下来（contrast 一直在给大字加分）。所以让 contrast 随
#     字号**单调降到 0**，大字只剩 gamma 起作用。
#
#   未覆盖的字号在相邻两点间线性插值；超出两端取端点值（不外推斜率）。
#
# ══════════════════════════════════════════════════════════════
# 怎么调（体系的意义：改文件即可，不必重编译）
# ══════════════════════════════════════════════════════════════

#   1. 跑 `python tools/dw_ab_sizecurve.py` 看各档实测；
