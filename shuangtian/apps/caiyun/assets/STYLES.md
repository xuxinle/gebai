## 一、复用内核 `_kit.js`

把 `_kit.js` 整段粘到 layout 脚本最前面即可用。三块内容：

### A. 运动学

```js
const k = spring(t - t0, 0.62, 18);   // 欠阻尼弹簧：可超过 1（过冲）
const u = EASE.expoOut(seg(t, 0.4, 1.2));  // 快起慢收
const v = splineKnots([{t:0,v:0},{t:1,v:1}], t);  // 连续可导（keys 是分段线性）
const d = staggerDelay(i, 0.2, 0.06, 0.04);  // 错峰：base + i*step + 波浪
const r = radialDelay(x, y, cx, cy, maxR, 0, 0.6);  // 从中心向外错峰
const n = noise1(t * 1.7, seed);      // 确定性噪声（**不用 Math.random**）
```

**为什么值得用**：裁云自带 `keys()` 是分段线性，速度在关键帧处突变，读作"一顿一顿"。
同一个 8 帧位移，`linear` 读作"被拖动"，`spring` 读作"弹过去的"。
这是"机械感"与"生命感"的唯一差别来源。

### B. 等轴测 / 弱透视实体

```js
// 装置 / 阵列 / 方块堆 → 等轴测
const P = isoProj(W/2, H/2+200, 1.0, yaw);
isoBox(shapes, P, x, y, z, w, d, h, '#E8912E', 0.95);
isoShadow(shapes, P, x, y, 0, w, d, 0.8, '#8A7060');   // **必须有**，否则像贴纸
isoBall(shapes, P, x, y, z, r, '#2EC4B6', 0.95);

// 人形 / 机器人 → 弱透视（等轴测会把身体压成柱子）
const P2 = perspProj(W/2, groundY, 1.9, yaw);
```

三条实测规则：

1. **三面顶点索引必须选可见面**：顶 `[4,5,6,7]` / `x+w` 面 `[1,5,6,2]` / `y+d` 面 `[3,2,6,7]`。
   画成 `x=0` 的背面会让相邻方块**互相穿透**（出现大片直角三角）。
2. **绘制顺序**：按 `(x+y)` 从远到近；同深度再按 `z` 从低到高。
   光照类图层（梁、索）要**强制先画**，否则会穿过主体。
3. **接触阴影三层叠加**，单层有硬边。

### C. 图元

```js
textCentered(shapes, W, '标题', y, 46, '#EDEFF3', 1);
scanBand(shapes, W, H, lt, '#FFFFFF', 0.018, 2.8);      // 扫描光带（最后画）
breatheLayer(shapes, W, H, lt, '#FFFFFF', 0.004, 0.018, 0.36);  // 呼吸
```

**文字居中不要用 `align: 1`** —— 实测行为与预期不符（文字被推到左边）。
手算字宽最稳（中文 1.0em / ASCII 0.52em）。

## 二、13 种风格配方

每种都是**完整的视觉系统**，不是配色。共用同一方法：**一个概念 + 一种材质/介质 + 一条时间线**。

### 1 · knockon —— 纸面 + 柔投影

| 项 | 值 |
|---|---|
| 底 | 米白 `#F2EFE8` + 每 7px 一条 `#E8E4DA` alpha 0.10 的纸纹 |
| 强调 | 单一朱红 `#F04E23`（只出现在"要被注意的那个"上） |
| 元素 | 圆角块 + **三层柔投影**（`alpha 0.030/0.020/0.010`） |
| 运动 | 横向滚动 + **残影**（同一元素画 4 个递减 alpha 重影，偏移 14px） |

两个坑：**纸纹 5px/alpha 0.28 会叠出摩尔纹**（斜向亮带），改 7px/0.10；
**纸面不能加白色脉动蒙版**（亮度整体抬 9 级，像蒙灰雾），用暗色。

### 2 · pith —— 终端橙光 + 极浅景深

| 项 | 值 |
|---|---|
| 底 | 纯黑 `#000000` |
| 色 | 琥珀 `#FFA000` + 绿 `#7DD87D` + 暗橙 `#6B5533` |
| 字体 | 等宽（Consolas / Cascadia Mono） |
| 景深 | **自己做**：按到焦点行距离衰减 alpha，远处再叠 4 次偏移低 alpha 的"晕开" |

**不要用场景级 `dof`** —— 它会把整个画面糊掉，包括要读的那行。

### 3 · clearing —— 单色 UI 微距

| 项 | 值 |
|---|---|
| 底 | 单一宝蓝 `#2B44D4` |
| 层级 | 只靠明度：`#4A63E8` / `#5B74F0` / `#8B9BFF` |
| 元素 | **大量重复**（日历块 20+），铺满并**溢出画面** |
| 强调 | 唯一黄 `#FFD84D`（空闲时段） |

**一加第二个色相就散**。

### 4 · unbroken —— 分屏对比 + 束状笔触

| 项 | 值 |
|---|---|
| 底 | 近黑 `#0D0D10` |
| 笔触 | 米白 `#E8E4D8`，**一笔 = 14 条平行细线沿法线偏移** |
| 分屏 | 中间 1px 竖线，左右各一个场景 |
| 字体 | 等宽小号 `#8B8B95` |

笔触不能是一根粗 stroke——必须是几十条细线叠加，才读出"笔刷"。

### 5 · ebb —— 暖橙单色 + 超大数字

| 项 | 值 |
|---|---|
| 底 | `#F0B896` → `#E8A882` 竖向渐变（40 条横带） |
| 主体 | 巨大数字占屏 60%，笔画宽 26px，白色 |
| 细节 | 极小灰字 `#B08A70`（24~26px） |
| 运动 | 底部光涌（大半径浅色圆随时间上浮） |

靠**字号对比**（420px vs 24px）造成冲击，不用多色。

### 6 · overlap —— 孔版印刷（risograph）

| 项 | 值 |
|---|---|
| 底 | 米白 `#F4F1EA` |
| 双色 | 品红 `#E8418D` + 青蓝 `#1B6FA8`（**只有两色**） |
| 元素 | 网点阵，格距 34px、半径 9.5px |
| 关键 | 第二版**错开半格**（`+G*0.5`）→ 交叠处出现第三种颜色 |
| 细节 | 四角套准标记（十字圆） |

网点必须真的错位，否则没有"叠色"这回事。

### 7 · infra —— 柔光渐变 + 极简

| 项 | 值 |
|---|---|
| 底 | 深紫 `#2A1B3D` |
| 渐变 | **5 个大半径斑块**（520~640px）各自漂移，每块用 5 层同心圆叠柔边 |
| 色 | `#E88BC8` `#FF9955` `#8B7BE8` `#5B6EE8` `#4AC8D8` |
| UI | 一个白胶囊 + 四角小字 |

**渐变不是线性**——是多个大斑块叠加。

### 8 · clawd —— 浅底 + 实体 + 清晰投影（**成品示例**）

见 `slot-robot-example.js`。这是唯一保留的完整示例，因为它同时覆盖了：
浅底渐变、弱透视实体拼装、关节式姿态、时间线点亮、弹簧落地、
能量传导、扩散环、景深层次、手算居中文字。

### 9 · one-dot —— 黑底大字跑马

| 项 | 值 |
|---|---|
| 底 | `#0A0A0C` + 40px 间距的极淡网格点 |
| 文字 | 128px 无衬线，白色；一行紫 `#7C5CFF` |
| 运动 | 整行横向跑马（210~400 px/s，各行不同），光标块跟随闪烁 |

### 10 · domino —— 3D 阵列 + 尺度揭示

| 项 | 值 |
|---|---|
| 底 | 深灰 `#2A2A2E` |
| 主体 | 625 个实体积木（25×25），高度由"图案函数"决定 |
| 手法 | **尺度揭示**：`scale` 从 0.10 拉到 0.96，微距 → 全景 |
| 冲击 | 靠**数量**与尺度反差，不靠颜色 |

### 11 · launch —— 品牌收尾

| 项 | 值 |
|---|---|
| 底 | `#08080A` |
| 运动 | 90 个粒子从四周向中心汇聚（各自速度/相位不同） |
| 主体 | 中心光核脉动 + 132px 大字 + 展开的细线 |
| 收尾 | 呼吸周期拉长到 1.1s（读作"平静下来"） |

## 三、跨风格的三条硬规则

### 1. 浅底与深底的脉动方向相反

- 深底：`#FFFFFF` alpha 0.004~0.03（提亮）
- 浅底：`#000000` / 暗色 alpha 0.004~0.02（压暗）

用错方向会让画面"发灰"或"发脏"。

### 2. `layers` 先画、`shapes` 后画

用 `shapes` 画全屏背景会**完全盖住 `model3d`**。
需要背景就交给场景的 `background` 字段。

### 3. 没有 `layout` 字段的场景会沿用上一个场景的脚本

`motion.cpp` 里 `if (engine.loaded())` 是无条件的，而装载只在 `!scene.layout.empty()` 时触发。
**不想要 layout 的场景也要挂一个返回空数组的脚本**。

## 四、验片

```powershell
$env:CAIYUN_SHAPES_DEBUG="1"   # 先确认代码真的执行了
caiyun.exe --headless --script x.json --render out.mp4
py scripts/probe_scene.py --script x.json --scene 0   # 单段秒级量化
```

量尺口径：32×18 网格（每格 60px），逐格均值差 <1.2 算静止。
**能测到的**：明暗在跳、存在感在变（线从 8% 到 92%）、位移跨整格。
**测不到的**：匀速平移、连续旋转、纯色大块整体移动。
