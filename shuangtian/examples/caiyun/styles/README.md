# 裁云 · 风格模板一镜示例

七个模板各一个**一镜**示例（4~6s / 1080p30 / 零音效 / 歌白主题）。
配套的方法论在**裁云子 Agent 的 `styles/` 资源**里（`caiyun_style_guide` 工具读取：
`name=overview` 读总纲，`name=<模板>` 读那一套的九个字段）——
本目录是它的可运行参照物。

## 为什么每个示例只有一镜

这些工程是**风格模板的参照物**，不是七部片子。一镜刚好够读出一个模板的
「承接方式」——而那正是模板之间唯一的本质差别。做成一整部片会让每个模板的
特性被叙事稀释，反而不好对照。

## 目录约定（**只入库脚本，不入库产物**）

```
styles/
  render_all.py           渲染驱动（拼 kit → 渲染 → **静默降级检查**）
  measure_motion.py       动效量测（静止占比 / 变化密度 / 落定窗）
  01-capability-list/
    film.json             导演脚本（图层与场景）
    layout.js             脚本编排层（动效）
  ...
```

`_build/`（kit 拼接产物与 resolved json）、`*.mp4`、`frames/` 都在 `.gitignore` 里。
**成片与抽帧一律落会话目录**，不落这里。

## 用法

```bash
# 全渲（产物落会话目录）
py render_all.py --out <会话目录>/styles

# 只渲一个
py render_all.py --only 03 --out <会话目录>/styles

# 量测（先抽帧）
ffmpeg -v error -i <成片>.mp4 -fps_mode passthrough frames/f%05d.png
py measure_motion.py frames
```

`render_all.py` 渲完会做一次**静默降级检查**：裁云的 layout 脚本出错时
会静默降级为纯 JSON、照常出片（画面停在初始帧、零报错）。检查器量「中段平均
maxdiff」，低于 20 就报警——这个判据经过两次逆向验证才定下来，演进过程写在
脚本注释里。

## 七个模板

| # | 目录 | 一句话 | 承接靠什么 |
|---|---|---|---|
| 1 | `01-capability-list` | 并列报出多项能力，每项一个物理反馈 | 手是开关 + 硬切 |
| 2 | `02-single-point` | 一个元素连续变形演完全片 | 它自己 morph |
| 3 | `03-causal-chain` | 每次撞击启动下一次 | 上一次的动量 |
| 4 | `04-scale-dive` | 一次连续运动穿越所有尺度 | 同一个主体 |
| 5 | `05-contrast-split` | 两态并置，让观众自己看出差异 | 比较 |
| 6 | `06-spine` | 一条主线往复产出多个产物 | 主线变形 |
| 7 | `07-pointer` | 角色身体驱动每个界面反应 | 手即指针 |

## 写脚本前必读：裁云的六个静默失效面

这些都是本目录的示例**实际踩过**的（代价：每个都白渲两三轮才定位）：

1. **入口函数名必须是 `layout`**。写 `scene_xxx` 之类的名字 → 整层不装载。
2. **宿主只提供 7 个函数**：`ease` / `spring` / `spring_vel` / `settle` /
   `lerp` / `clamp` / `snap`（+ `noise`）。**没有 `seg`、没有 `E.*`、没有 `D()`**——
   用了就 ReferenceError → 整份降级。
3. **`spring` 在负 tau 上不为 0**：`clamp(spring(t - t0, ...))` 会让所有
   "还没开始"的动效一开始就是完成态。必须自己用 `t < t0 ? 0 : ...` 挡住。
4. **`layout` 的路径基准是 json 文件所在目录**，不是工作目录。
5. **`opacity: 0` 的图层永远点不亮**（`alpha` 是乘数）。
6. **`line` 的 `w`/`h` 是终点增量**；`dw`/`dh` 是**右下单向**增长，
   要"对中增长"必须自己补 `dx = -dw/2`。

**这六条的共性**：写错不报错，画面停在初始帧，渲染成功、退出码 0。
所以改完脚本第一件事不是看画面，是看 `render_all.py` 的降级检查有没有报警。
