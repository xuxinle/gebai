# 剧本 · 歌白（GEBAI Agent）炫技片

> 目标：用裁云的全部能力（三维 / 粒子 / 编排脚本 / 音响 / 运镜 / 光效），
> 把歌白的核心概念拍成一支有说服力的短片。**技术即内容**：片子本身就是证据。

## 1. 定位

| 项 | 值 |
|---|---|
| 受众 | 第一次听说歌白的技术人（开发者 / 架构决策者） |
| 看完记住的一句 | **一个 TS 文件就是一个子Agent；它能改自己的代码。** |
| 时长 | 26 秒（8 个场景） |
| 画幅 | 1920×1080 / 30fps |
| 语言 | 中文主标 + 英文副标 |
| 声音 | 配乐（calm，bpm 92）+ 5 句配音，**零音效**（纪律 6.0） |

**为什么不拍"功能罗列"**：歌白有 23 个子Agent，逐个展示会变成 40 秒的清单视频，
观众一个都记不住。选**一条主线**：能力是"长出来"的（从 1 到 23），
而长出来的机制是"代码即能力"。

## 2. 内容结构（能量走向）

| 段 | 时间 | 让观众产生什么反应 | 手法 |
|---|---|---|---|
| ① 起点 | 0–3.5s | 「这是什么」 | 一点光在暗处亮起，微距 |
| ② 躯体 | 3.5–8s | 「有实体」 | **三维**：多面体在光里成形、自转 |
| ③ 一次调用 | 8–11.5s | 「它在做事」 | 卡片流过，审批点亮 |
| ④ 长出来 | 11.5–16s | 「**能扩展**」← 核心 | 1 → 23 个方块按波次生长 |
| ⑤ 收编 | 16–20s | 「什么都能接」 | 外部进程/语言汇入一个环 |
| ⑥ 改自己 | 20–23s | 「**它会进化**」← 第二个核心 | 代码行自我改写，高亮扫过 |
| ⑦ 字标 | 23–26s | 记住名字 | 歌白 + 英文 |

能量：低开（0–3.5 只有一点）→ 起（三维成形）→ 平（调用）→ **峰（1→23 爆发）**
→ 收（收编成环）→ 二次峰（自我改写）→ 静（字标）。

## 3. 逐镜设计

### ① 起点（0–3.5s）
- 画面：纯黑。中央一点琥珀光，半径 2px → 120px 缓慢呼吸。
- 文字（0.8s 起）：`融合旧世界 IT 的所有技术`（副标：`FUSE EVERY OLD-WORLD TECH`）
- 动效：光点 `scale 1.0 → 1.35 → 1.0`（一个呼吸周期 1.4s），**落定后静止 1.2s**
- 采样帧：0.5s（光点）、2.0s（呼吸峰）、3.2s（静止）
- 转场：光点炸开成粒子 → 粒子聚成多面体（14 条粒子轨迹）

### ② 躯体（3.5–8s）
- **三维**：`model3d` 二十面体，`model_color` 琥珀 → `model_color_alt` 深蓝渐变。
- 自转 **10 度/秒**（纪律：8~15 是"缓慢自转"，20 以上像陀螺）
- 光照：侧逆光 `light_azimuth 135` + `light_rim 0.45`（体积感）
- 相机：`cam_dolly_from 1.0 → cam_dolly_to 0.86`（缓慢推近）
- 文字：`打造新世界智能的躯体`（副标 `A BODY FOR NEW-WORLD INTELLIGENCE`）
- **落定后静止 1.4s**（字标级标准）
- 采样帧：4.2s（入场中）、5.8s（自转中）、7.4s（落定）

### ③ 一次调用（8–11.5s）
- 画面：左侧流出 4 张卡片（工具调用），每张右侧一个「审批」小盾牌点亮。
- **编排脚本 `geibai.js`**：卡片按 `stagger 0.22s` 错峰入场，盾牌在卡片到位后 0.15s 亮。
- 文字：`每次工具调用都是智体的行为`
- 采样帧：8.6s（第一张入场）、9.8s（三张在位）、11.2s（全在位+盾牌亮）

### ④ 长出来（11.5–16s）★ 峰值
- 画面：中央一个方块，然后**按波次**裂变成 23 个（每波 6 个，间隔 0.28s）。
- 每个方块上一个点，代表一个子Agent。**按到中心的距离错峰**（不是同时）。
- 文字：`一个 TS 文件 = 一个子Agent`（数字 23 用大字，68px）
- 动效：方块 `scale 0 → 1`（`ease out back`），带 0.06s 的过冲
- **这是全片最强运动段**：23 个方块 + 中央爆炸环
- 采样帧：12.0s（第一波）、13.5s（中段）、15.2s（全在位）

### ⑤ 收编（16–20s）
- 画面：外围出现 5 个不同颜色的环段（代表 TS/Python/C++/Rust/Go），
  依次**汇入**中央的环，合并成一个完整圆环。
- 文字：`能力外置` / `权力内守`（两行，上下错开）
- 动效：环段沿弧线滑入（`rotate + scale`），合拢时一次 `glow` 脉冲
- 采样帧：16.8s（分散）、18.4s（汇入中）、19.6s（合拢）

### ⑥ 改自己（20–23s）★ 二次峰
- 画面：一片代码行（等宽字体），一行被**高亮**，然后内容**就地改写**（字符逐个替换）。
- 动效：高亮条从左扫到右（0.5s），扫过处字符变（`layout` 脚本控制）
- 文字：`Agent 能改自己的代码`
- 采样帧：20.5s（高亮进入）、21.4s（改写中）、22.6s（完成）

### ⑦ 字标（23–26s）
- 画面：歌白大字（`GEBAI` 拉丁 + `歌白` 中文），下方一行小字
- 文字：`歌白` / `GEBAI AGENT` / `极致动态扩展的人工智能体`
- **静止 ≥2s**（纪律 3）
- 采样帧：24.0s、25.5s

## 5. 声音设计

| 项 | 内容 |
|---|---|
| 配乐 | `style: calm`，`bpm 92`，`gain 0.30`（歌白默认） |
| 配音 | 5 句，神经 TTS（女声，中速） |
| **音效** | **零**（纪律 6.0：裁云不对 `audio.voice` 做 ducking，音效会盖旁白） |

配音文案（逐句，实测时长后重排镜头）：

1. `融合旧世界 I T 的所有技术。`（0.8s 起）
2. `打造新世界智能的躯体。`（3.6s 起）
3. `每一次工具调用，都是智体的行为。`（8.2s 起）
4. `一个 T S 文件，就是一个子 Agent。二十三个，还会更多。`（11.8s 起）
5. `能力外置，权力内守。它能改自己的代码。`（16.2s 起）

> 数字与缩写已按"读出来是什么样"改写（`IT` → `I T`、`TS` → `T S`）。
> 第 5 句刻意把两段概念合成一句，压在第 ⑤⑥ 段上。

## 8. 风险与已知边界

1. **三维是"近似"**：裁云的 `Scene3D` 没有真阴影贴图/AO/反射。
   靠**侧逆光 + 接触阴影 + 暗底**营造体积感，不追求写实。
2. **逐字改写需要 layout 脚本**：`shapes` 坐标是**屏幕像素**（不过相机），
   后 push 的在上层 —— 这两条已踩过（见 PITFALLS〔编排〕）。
3. **台词 5 句 ≈ 22 秒**，与 26 秒片长留 4 秒呼吸，不做"字追画面"。
