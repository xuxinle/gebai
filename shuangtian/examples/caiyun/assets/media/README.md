# 素材目录（裁云 / 镂月共用）

这里的 PNG 是**作品的一部分**，随仓库一起走。两个示例都读这个目录：

- 裁云：脚本里写 `"image": "media/bg-aurora.png"`（相对脚本目录）或 `"image": "bg-aurora"`（按素材库名字）
- 镂月：海报块里写 `"image": "bg-aurora"`

## 这批图怎么来的

由本地 **SDXL-Turbo** 生成（`tools/gen_gebai_assets.py`），**不是**手绘或下载的外部图。
1024×576，每张 0.6~2 秒（RTX 4080 SUPER，3 步）。

生成取向写在脚本里，两条都是实测得出的：

1. **题材要"柔"**：底板必须能在压暗后仍让白字读得清。星云/电路这类高频题材虽然好看，
   但细节密到叠字后糊成一片（试过，弃用）——现在只用渐变、雾光、单色纹理。
2. **提示词统一追加底板约束**（低对比 + 大留白 + 柔和过渡），省得每条手写。

## 规则

1. **不要让模型画文字**：它没有排版能力，出来的是扭曲字母。文字一律交给渲染器。
2. **新增素材优先用 `imagegen` 工具生成**（`imagegen` → 直接落进这个目录），
   而不是往这里塞大图——仓库里只留"作品用得到的那一批"。
3. 想换风格就改 `gen_gebai_assets.py` 里的提示词重跑（`--force` 覆盖），
   再跑一次 `louyue_poster_e2e.py` / `caiyun_director_e2e.py` 确认没把对照断言打破。
4. **压暗量（`image_dim`）与素材对比度是一对参数**：这批图本身低对比，压暗 0.22~0.35 即可；
   若换成高对比素材（如照片），要加到 0.45~0.6，否则文字读不出来。

## 命名

`bg-*` 背景板、`tex-*` 纹理、`texture-*` 质感、`accent-*` 点缀/光效。名字会被脚本直接引用，
**改名等于改作品**——改名前先 `grep` 一遍 `examples/` 下的 JSON。
