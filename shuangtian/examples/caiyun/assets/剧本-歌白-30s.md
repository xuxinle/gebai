# 剧本 · 歌白（GEBAI Agent）30 秒宣传片 + 竖版海报

> 本文件先于脚本存在。脚本是它的执行。
> 依据：`README.md`(1-422)、`DESIGN.md`(定位/核心不变式/子Agent/自我优化)、
> `packages/agents/src/agents/*`(22 个子Agent目录)、`keqing/*`(cpp/go/python/rust)、
> `packages/web/src/themes/*.css`(10 套主题，acrylic 强调色 `#8b9aff`)。

## 第一部分：定位

| 项 | 内容 |
|---|---|
| **一句话定位** | 给懂技术的人看，看完记住「**能力外置、权力内守**」——一个能收编任意技术、也能改自己代码的智体 |
| **受众** | 开发者 / 架构师 / 想要私有化部署智能体的人。关心：能不能扩展、能不能审计、能不能自己长 |

| **语言与声音** | 中文文案 + 拉丁副标；6 条中文配音（Kangkang，男声，语速 -5%）+ 6 条音效；内置合成配乐 uplift 108BPM |

| 段 | 作用 | 观众反应 | 场景 | 时长 |

能量走向：**低开（暗场单光）→ 立传（大字静止）→ 爬升（四段证据，节奏交替）
→ 峰值（diff 卡：红绿对照，全片唯一的"对比色"）→ 自证（霜天：这条片子自己做的）
→ 落地（三端）→ 归于一点（标志环 + 字标静止 1.2s）**。

**为什么霜天必须在片子里**：它不是又一个功能，而是「融合旧世界 IT」的**实证**——
一套 C++ 自研原生 UI 框架 + 自研光栅器，裁云（视频渲染器）与镂月（海报渲染器）
都长在它上面；而**这条片子本身就是由它的霜天子 Agent 驱动渲染出来的**。
这是全片唯一一处「画面在证明自己」，比任何形容词都硬。
