# 歌白宣传片的旁白轨（`vo/` 目录）

`gebai-promo.json` 引用了四条旁白：`vo/s1.wav` ~ `vo/s4.wav`，分别落在四个分镜上。

**这四条 WAV 不入仓**（`.gitignore` 已忽略本目录）：它们是**语音合成生成的外部产物**
——二进制、可由文本重新生成、且与具体音色/引擎绑定。仓库里留的应该是**脚本 + 文本 +
生成方式**，而不是音频本身。

## 缺席时会怎样

不会失败，也不会静默。渲染日志会明确写出：

```
配音：0/4 轨已混入
配音轨读不到：.../vo/s1.wav
配音轨读不到：.../vo/s2.wav
...
```

成片照常产出**配乐 + 画面**，只是没有人声。这是刻意的：配音是外部产物，缺席是常态，
不该让整条渲染链失败；但「成片正常、就是没人声」必须能被看见。

## 怎么生成

用任意 TTS 引擎（本机离线、在线 API、录音均可），合成 16 位 PCM 单声道 WAV
（16k / 44.1k 都行，渲染时会重采样到 44.1k），按下表命名放到本目录：

| 文件 | 起点（秒） | 台词 |
|---|---|---|
| `s1.wav` | 0.35 | 歌白智能体。 |
| `s2.wav` | 2.55 | 一个文件，定义一个子 Agent。 |
| `s3.wav` | 5.15 | 能力外置，权力内守。 |
| `s4.wav` | 7.55 | 一个二进制，三端合一。 |

起点与台词都改在 `gebai-promo.json` 的 `audio.voice` / 对应分镜的 `title` 上——
**脚本是真值源**，本文件只是生成说明。

## 为什么不让裁云自己合成语音

霜天是原生 UI 框架，**不含语音合成引擎**（那是平台能力，与窗口后端一样属宿主职责）。
分工写在 `director.hpp` 的 `VoiceTrack` 注释上：**AI/宿主侧生成人声 WAV，裁云负责
混音（含人声段配乐自动压到 35%）与封装**。把 TTS 塞进框架会让「出片」依赖某个
具体平台的语音引擎，与跨平台目标冲突。
