# gotime 子代理

时间日期工具集：当前时间（多时区/多格式）、时间文本解析（→ unix 时间戳）、时长解析与全单位换算。
常驻进程，纳秒级调用开销——调度计算、日志对时、倒计时换算的趁手工具。

## 工具

| 工具 | 功能 |
|------|------|
| `now` | 当前时间：`tz`（IANA 时区如 Asia/Shanghai/UTC）+ `format`（Go 布局或 datetime/date/time/rfc3339/unix 别名） |
| `parse` | 时间文本 → unix 秒/毫秒 + RFC3339 + 本地时间（支持 RFC3339、2006-01-02[ 15:04[:05]]、2006/01/02、unix 秒；`tz` 指定无时区文本的解释时区） |
| `duration` | 时长解析与全单位换算（Go 语法 1h30m/500ms/90（纯数字按秒）→ ns…d 七档 + 人性化描述） |

## 用途

- 跨时区会议/日志时间对齐
- 定时任务时间戳计算（cron/webhook 触发时刻）
- 「1.5h 是多少秒/毫秒」这类换算一次到位
