# 体裁：周报 / 进展报告

**读者任务**：判断当前相对目标或承诺的位置，决定要不要介入。

**骨架**：总体状态（红黄绿 + 判据）→ 相对基线的产出（delta）→ 偏差/风险/依赖 → 下一里程碑 → 需要的支持（ask）。

**硬约束**
- 标对象、周期与截至时间；进展用已验收产出或有口径指标，会议数、沟通次数、投入时长不算进展。
- 状态色必须有预先定义或就近说明的判据；无基线就写「无法判断是否按计划」，不默认绿色。
- 事实、当前状态、下期计划分开；不确定的完成率/原因/责任人在写 unknown，不猜。
- ask 写明对象、事项、需要的时间；关键数据延迟时说明最近可用时间点及其对判断的影响。

**常见错误**：活动流水账；无周期无基线；health 色无判据；风险埋在末尾；猜根因冒充事实；下一步没有里程碑；ask 不可执行。
