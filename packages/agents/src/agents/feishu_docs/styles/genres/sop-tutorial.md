# 体裁：SOP / 操作教程

**读者任务**：照着做就能稳定复现，出错时能恢复。

**骨架**：适用场景与前置条件（权限、环境、版本、依赖）→ 总览流程（图示）→ 分步操作（每步：命令/截图 + 预期结果 + 失败怎么办）→ 验证方法 → 回滚/恢复 → 常见问题。

**硬约束**
- 步骤编号连续，一步一个动作；命令用代码块并标环境与语言，必要时加 `caption` 说明用途。
- 关键步骤写「预期看到什么」，让读者能自检；不可逆操作必须写前置备份。
- 首次出现的术语/变量给定义或取值来源。

**常见错误**：跳步；命令缺参数说明；没有验证步骤；没有回滚路径；截图无说明；把内部脚本当成读者可执行的前提。
