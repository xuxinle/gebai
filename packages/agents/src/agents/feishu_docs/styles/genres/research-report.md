# 体裁：研究报告 / 调研

**读者任务**：形成对某个问题的判断，并知道证据强度与不确定性。

**骨架**：要回答的问题 → 结论摘要（先给答案）→ 方法与范围（来源、时间窗、样本、口径）→ 分维度发现（每条结论附证据）→ 反例与竞争解释 → 局限与不确定 → 建议与下一步。

**硬约束**
- 每个结论可溯源（来源 + 日期）；区分数据、推断与观点。
- 证据冲突时并列保留并标注口径差异，不挑对自己结论有利的一项。
- 不给没有证据的确定性表述；范围与样本不支持外推时明确写出。

**常见错误**：结论埋在最后；来源缺失或只有二手转述；以个例代替规律；不写局限；把相关性写成因果。
