# 体裁：复盘

**读者任务**：解释已结束周期为何如此，并改变下一轮做法。

**骨架**：目标与预期 → 实际结果与数据 → 时间线与关键节点 → 做对了什么（可复用）→ 做错了什么（根因，不追责）→ 意外与外部因素 → 下一轮具体改变（谁、何时、怎么验证）。

**硬约束**
- 结论回链证据（数据、日志、记录）；严格区分事实与事后解释。
- 改进项必须可执行、可验证、有责任人与时点，避免「加强沟通」这类空话。
- 区分「已结束周期的解释」与「未来计划」；计划部分不塞进复盘结论。

**常见错误**：流水账；只有感受没有数据；把归因当事实；改进项无 owner 无时点；把复盘写成周报。
