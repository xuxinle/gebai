# 体裁：备忘 / 简报（Memo / Brief）

**读者任务**：让具名内部读者快速知悉、判断，或完成会前准备。

**骨架**（三选一主模式，先定模式再写）
- 信息 Brief：变化 → 影响 → 当前状态与风险 → 下一步（无须行动时明确「仅供知悉」）。
- 决策 Memo：决定事项与时点 → 现状 → 真实选项及同口径影响 → 推荐与证据 → 明确决策入口。
- 会前 Brief：会议目标 → 已核验的参与方立场与利益 → 要点与禁区 → 期望结果。

**硬约束**
- 首屏给结论、状态或 ask；按重要性而非材料顺序组织，一段一个观点。
- 事实、数字、立场、审批状态与时点均须可核验；未知与假设就近标记（`[关键结论待确认]`、`[数据口径待核]`），未知立场不得补造。
- 标读者、责任团队、日期与信息截至时间；持续更新时说明相对上版的变化与下次更新点。

**常见错误**：首屏无结论或 ask；把完整方案压成摘要冒充决策材料；编造审批或立场；用固定篇幅删掉证据；细节不解释影响。
