# 体裁：白皮书（White Paper）

**读者任务**：让专业读者系统理解并**评估**一个问题、框架或方案（不是获客材料）。

**骨架**：要解决的问题与读者目标 → 结论/主张与依据强度 → 背景与术语界定 → 框架或方案（分层展开）→ 证据与反例、竞争解释 → 边界、前提与失败条件 → 落地路径与评估方法 → 参考与延伸阅读。

**硬约束**
- 术语首次出现给定义；同一概念全文同名，不随段落换说法。
- 每个主张附证据或明确标为观点/假设；证据冲突时并列保留并说明口径差异。
- 必须写**边界与失败条件**：方案在什么前提下成立、什么情况下不成立。
- 面向专业读者，不用营销口吻；获客、产品卖点或 CTA 为主时改用提案/营销体裁。

**常见错误**：结论先行却无依据；只列优点不写代价与失败条件；用行业黑话替代定义；把个案当规律；篇幅堆砌而无评估路径。
