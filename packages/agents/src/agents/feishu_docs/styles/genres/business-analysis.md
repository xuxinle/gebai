# 体裁：商业分析（Business Analysis）

**读者任务**：比较投资、资源、市场、产品、经营或供应选项并支持判断——**但正文不要求具名决策者作出选择或批准**。

**骨架**：推荐与适用条件 → 变化动因 / 目标 / 现状基准 → 选项生成与排除理由、同口径比较 → 关键假设、风险、情景与翻转条件 → 建议为何优于替代 → 阶段门、监测/学习计划与未决条件。

**硬约束**
- 围绕一个具体决策比较**现状/不行动**与真实替代项；用统一目标与口径评价价值、全生命周期成本、风险、约束与可实施性。
- 数字标来源、时点、单位、口径与置信范围；现状数据与预测分开；不得从公开标价推断销量、收入或份额。
- 对可能翻转结论的假设做范围/情景/敏感性分析，给出切换值、决策门或验证信号；评分模型须解释权重与证据。
- **分析建议不等于批准或承诺**；谁获益、谁承担成本要写明。
- 缺目标、成功标准、基准或可行选项时只产出 decision frame / 选项清单，并把关键估算标 `[成本区间待核]`。

**常见错误**：为预选方案找论据；无现状基准或真实替代项；口径不一却排名；单一 ROI/BCR/评分替代平衡判断；套 SWOT；估算冒充事实；忽略全周期成本与分配影响；未获批写成已承诺。
