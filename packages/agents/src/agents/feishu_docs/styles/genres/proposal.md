# 体裁：方案 / 提案（要不要做）

**读者任务**：判断该不该投入资源——方向、优先级、预算。

**骨架**：决策问题一句话 → 现状与机会/问题证据 → 备选方案（含「不做」）→ 评估维度与同口径对比（表格宜用分栏或表格并排）→ 推荐与理由 → 成本/收益/风险与缓解 → 决策点与时间窗 → 需要的批准。

**硬约束**
- 对比必须同维度、同口径；成本收益给区间与假设，不给单点伪精确。
- 风险写影响与缓解手段，不写「有一定风险」。
- 明确不做什么；推荐结论必须有，不能只罗列选项。

**常见错误**：把 PRD 塞进提案；只讲好处没有取舍；没有推荐结论；决策点模糊（「后续再看」）。
