# 体裁：法定公文（红头文件）

**读者任务**：作为权威依据被引用、执行或留档。

**骨架**：标题（发文机关 + 事由 + 文种）→ 主送机关 → 正文（依据/缘由 → 事项 → 要求）→ 附件说明 → 发文机关署名与成文日期 → 抄送与印发说明。

**硬约束**
- 视觉档位 `formal`：不使用 emoji、高亮块、彩色单元格等装饰性组件。
- 编号与层级用中文体系 `一、→（一）→ 1.→（1）`，全程一套；**绝不出现「一、」下接「1.1」**。
- 文种与行文关系要匹配（上行文/下行文/平行文），不用「通知」代替一切；主送、抄送对象明确。
- 措辞用规范词：应当 / 不得 / 须 / 可；条件与例外写全；数量、期限、责任主体可执行可核查。
- 附件在正文先提后附，名称与文号写全；引用其他文件写清标题与文号。
- 段落首行缩进两格（Markdown 导入时行首用两个全角空格）。

**常见错误**：层级编号混用；中英标点混排；用形容词代替可执行要求（「尽快研究」「高度重视」）；主送/抄送缺失或错位；附件未在正文提及；正文夹带聊天式口吻。
