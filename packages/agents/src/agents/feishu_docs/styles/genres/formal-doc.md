# 体裁：正式文档 / 公文

**读者任务**：作为规范依据被引用或留档。

**骨架**：标题 → 主送单位与编号等要素 → 正文（依据 → 事项 → 要求）→ 落款与日期 → 附件。

**硬约束**
- 视觉档位 `formal`：不使用 emoji、高亮块、彩色单元格等装饰性组件。
- 编号用中文手写体系 `一、→（一）→ 1.→（1）`，全程一套；**绝不出现「一、」下接「1.1」**（自动编号与非中文体系二选一）。
- 分段缩进两格（Markdown 导入用行首两个全角空格）；事项表述用规范词（应当/不得/须/可），条件与例外写全。
- 附件在正文中先提后附；引用其他文件写清名称与编号。

**常见错误**：层级编号混用；中英标点混排；用形容词代替可执行要求（「尽快研究」）；附件未在正文提及；正文里混入聊天式口吻。
