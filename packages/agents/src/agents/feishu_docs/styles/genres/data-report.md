# 体裁：数据报告 / 指标分析

**读者任务**：理解指标变化并决定动作。

**骨架**：指标口径与时间窗 → 总览（核心数字与变化）→ 分维度拆解（结构 / 趋势 / 异常）→ 归因（可验证假设与反证）→ 行动建议与预期影响 → 数据附录（口径、查询、来源）。

**硬约束**
- 每个数字带口径、单位、时间窗、来源；对比必须有基线。
- 变化给幅度与显著性，不用「大幅/明显」这类形容词；图表配标题、单位与数据标签，并配一句文字结论。
- 口径变化必须显式说明（否则会把口径变化读成增长）；多个数字冲突时并列并标注 `[口径待核]`。

**常见错误**：只贴数字不解读；用绝对量掩盖结构变化；拿无基线的一次性快照下结论；建议与数据无关。
