# 能力清单

**一句定位**：观众已经认同品类，需要被「它真的有用」说服。不叙事，报能力。

### 节拍结构

9 段 / 单 burst。实测节拍表（15s 片）：

| 段落 | 时长 | 内容 |
|---|---|---|
| 开场词 | 1.40s | 三个词弹入，**间隔 0.35s** |
| 立标 | 1.35s | 字标字母落入 + 落地压缩 |
| 第一次交互 | 1.75s | 打字（**38 字/秒**）+ 手进入点击 |
| 密集小项 | 2.15s | **7 行，每 0.24s 一勾** |
| 素材飞掠 | 2.70s | 3 张真实页面倾斜+模糊飞过，**各停 0.9s** |
| 能力卡 | 2.60s | 4 张微卡叠出 |
| 蓄力 | 1.15s | 窗口 hold，慢推 **1.00→1.07** |
| 断奏 | 1.05s | 硬切，**间隔 0.22~0.25s** |
| 落版 | 0.70s | 黑场 + 字标 |

**镜头长度离散度 CV 0.78**（最长/最短差 7×）。**全片静止 31%**，**只有 1 个 burst**。

能量走向：低（静场）→ 中（立标）→ 中高（交互）→ **中（故意降，密集小项）** →
高（飞掠）→ 高密（卡片）→ **中（蓄力）** → 极高（断奏）→ 零（黑场）。

### 视觉语言

- **白底 + 小元素**：元素小、留白大，但**内容占满画面**。这是本模板最容易做错的地方——
  「元素小」不等于「内容少」。做少得到的是「空」，不是「精致」。
- 强调色**只有一个**，它每次出现都意味着同一个东西。
- 收尾反转为深底浅字（明暗翻转本身就是落版）。
- UI 段几乎无阴影无强光：**靠对比与运动，不靠光**。

### 核心手法

**手**。每一次界面反应都看得见手——点、拖、按下。这是它区别于「纯 UI 录像」的唯一理由。
配角手法轮流上场，**每个只当一次主角**：弹簧进入 → 落地压缩 → 逐字打字 →
勾选序列 → 倾斜飞掠 → 磁吸按钮 → 弹簧跟随 → 果冻环 → 细线物理。

### 承接方式

**因果（手是开关）+ 尺度跳变 + 硬切**三段混合：

- 前段**因果**：手点 → 面板生成 → 判定 → 页面飞出
- 中段**尺度**：整页 → 卡片级细节
- 后段**剪辑节奏**：断奏硬切 + 黑场

### 声学

同一空间（混响 T60 **1.1s**）。三次玻璃触碰、字标一次呼吸、打字每三键一声、
每张页面一次空气掠过 + 毡垫落地、每张卡一个气泡、断奏四下低频、黑场最深一记。
峰值 **−8 dBFS**（保守）。**忌**：正弦「啵」、落版处撒碎屑音。

### 何时该用

- 有**真实素材/真实产品**可秀，观众已认同品类
- 需要展示**人在场**（工具类、编辑器类、创作类）
- 15s 内要报出 **6~8 个能力**

### 何时别用

- **零素材/纯概念**——会显得像功能列表，且复用别人的骨架会被说「没有创造力」
- 需要**一个连续世界**的叙事（它天然碎片拼接）
- 没有真实素材：飞掠段直接失效

### 用裁云怎么落地

```jsonc
// 每项能力 = 一张 card 图元 + 一次独立动效，靠 layout 脚本逐项错峰入场
{"kind":"custom", "duration":2.4, "layers":[
  // 容器：透明底卡（模拟界面）
  {"kind":"rect","name":"panel","x":420,"y":260,"w":1080,"h":560,
   "fill":"#0D1522","stroke":"#1E2D42","stroke_width":1,"radius":18},
  // 每一行：文字 + 勾选块（勾选块用 rect，靠 layout 给 alpha/scale 弹一下）
  {"kind":"text","name":"row0","x":470,"y":340,"w":600,"h":40,
   "text":"真源是 JSON","size":26,"color":"#C8D6EA","align":1},
  {"kind":"rect","name":"tick0","x":1400,"y":336,"w":20,"h":20,
   "fill":"#35C98A","radius":5},
  // 手：用 ellipse 画一个圆点作光标（裁云没有光标图元，圆点 + 拖尾线最省）
  {"kind":"ellipse","name":"hand","x":900,"y":800,"w":26,"h":26,"fill":"#FFFFFF"}
]}
```

`layout` 里每行按 `0.24s` 错峰给 `alpha` + `scale` 弹入；手用 `dx/dy` 沿路径移动，
**到点击位置时给一个 0.06s 的挤压**（`dw`+6 / `dh`−4，模拟按下）。
飞掠段用 `cam_zoom` + 大 `dx` 让卡片斜穿画面，离开时给 `alpha` 衰减。

> ⚠ 裁云**没有运动模糊**。所以「飞掠」要靠**停住**来补偿：飞 0.35s，停 0.9s。
> 停的那一下才是内容被读到的地方。
