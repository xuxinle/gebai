# 脊椎串联

**一句定位**：一条主线（一个输入框、一支笔、一条 prompt）产出多个产物，
每个产物有自己的世界。

### 节拍结构

主线出现 → 第一次输入 → 产出世界 A → **回到主线**（缩短）→ 产出世界 B → …
实测（30s，三段）：一句话 → 四个词 → 一个词，**每次输入都比上次短**。

**关键**：主线必须**可见地回来**。它不是转场工具，它是全片的脊椎——
观众每次都知道「我们又回到那条线上了」。

### 视觉语言

- 主线本身极简（一条线 + 光标），因为要反复出现
- 每个产物世界有**自己的配色与动效语汇**（这是「多产物」的读法：
  配色不同 = 不同的世界，而不是同一个世界换内容）
- 产物之间可能共用同一个台面（物理上放在同一张桌上），这样「回到主线」有空间依据

### 核心手法

**morphRect（主线变形）**：主线本身变成产物的入口。
输入框展开成窗口、笔迹收拢成图形。

### 承接方式

**主线变形**。活下来的是那条线。

### 声学

每次「回到主线」一个固定的回归音（同一个音，全片重复），
让观众靠听觉知道「又回来了」。产物世界各有质地。

### 何时该用

- 一个**输入**能产出多个不同**结果**（生成类、模板类、多产物工具）
- 想展示「同一入口，不同可能」
- 30s 左右、需要结构感的片子

### 何时别用

- 只有一个产物（那用模板 1 或 4）
- 产物之间没有共同入口
- 时长 < 10s（脊椎来不及建立就结束了）

### 用裁云怎么落地

主线 = 一个 `rect`（输入框）+ 一个 `line`（光标），全程在场，
靠 `layout` 改 `dw` 展开/收拢；产物 = 每段一组图层，`enter` 从主线的矩形位置长出。

```jsonc
// 主线（全片在场，z 序在最上）
{"kind":"rect","name":"spine","x":360,"y":700,"w":1200,"h":64,
 "fill":"#0D1522","stroke":"#2A3D57","stroke_width":1,"radius":14},
{"kind":"text","name":"prompt","x":390,"y":716,"w":1100,"h":36,
 "text":"","size":24,"color":"#C8D6EA","align":1},
// 产物 A（初始隐藏，等待从 spine 长出）
{"kind":"rect","name":"outA","x":360,"y":700,"w":1200,"h":64,
 "fill":"#101A2B","radius":14,"opacity":1}
```

「从主线长出」= `outA` 的 `dw/dh` 从 spine 的尺寸连续插值到目标尺寸，
同时 `dy` 上移。**不要用 `enter` 入场动画**——那是淡入，不是承接。

> ⚠ `opacity` 必须是 1（可见）。`layout` 的 `alpha` 是**乘数**，
> `opacity:0` 的图层永远点不亮（实测）。
