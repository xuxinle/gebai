# 对照分裂

**一句定位**：两态并置，让观众**自己看出**差异——不是讲给他听。

### 节拍结构

两态**同时**在场，前半段各自演化，后半段**一方让位**、镜头拉出、差异被放大。
实测（15s）：两态并行 ~7s → 一方消失 1.5s → 拉出揭示 3s → 落版。

**最贵的一条教训**：这部片子第一版「美术挺棒但没看出来啥意思」，
加**标注/箭头/文字说明**之后**更差**。最后把意思**做进画面本身**才成立——
两片网点纸在套准的瞬间浮出一个隐藏的 & 符号。

> **含义必须做在图形里，不能贴在图形上。**

### 视觉语言

- 两态用**同一套骨架**（同样的网格、同样的元素位置），只有「被干扰与否」不同
- 强调色两枚：一枚属于「你」，一枚属于「他/它」，全程不混用
- 印刷感（套准、网点、叠色）天然适合这个模板

### 核心手法

**并置（compare）**。两态永远同框，观众的眼在两者之间自动比较。
一旦拆成「先看 A 再切到 B」，比较就断了。

### 承接方式

**比较**：活下来的是「同一件事的两个版本」。

### 声学

两态各有自己的声音质地（干净的 vs 被打断的），
**中断的声音**是本模板的主角——每一次打断都是一个明确的短音。

### 何时该用

- 要讲「有它/没它」「旧/新」「一次 vs 十七次」这类**对照**
- 差异是**可视的**（形态、密度、完整度），不是纯逻辑差异
- 想避免「说教感」

### 何时别用

- 两态差异只能靠文字说清（那就不该用这个模板）
- 三态以上（同框超过两个会失焦）
- 需要线性叙事

### 用裁云怎么落地

两个并置区 = 两组图层，坐标镜像。差异靠 **`layout` 给不同的扰动函数**：

```jsonc
{"kind":"custom","duration":6.0,"layers":[
  // 左：被打断的那一版（12 段折线，每段被"抬起"错位）
  {"kind":"line","name":"L0","x":120,"y":300,"w":0,"h":0,"stroke":"#5B7391","stroke_width":3},
  // … L1..L11
  // 右：完整的那一版（同样 12 段，但连续）
  {"kind":"line","name":"R0","x":1000,"y":300,"w":0,"h":0,"stroke":"#8FB6F5","stroke_width":3}
]}
```

`layout` 里左侧每段 `dy` 加一个**递增的错位量**（第 i 段偏移 i*6px），
右侧 `dy` 连续。**差异不靠标注，靠错位本身**。

> ⚠ `line` 的 `w/h` 是**终点增量**（不是宽高）。画折线要给 `dh` 才有斜率，
> 只给 `dy` 会让所有段水平叠在一起（实测：曲线「消失」）。
