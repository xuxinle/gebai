# 因果链

**一句定位**：每一个画面由上一画面**撞**出来。不是「然后」，是「因为」。

### 节拍结构

节拍数量由「链的长度」决定，不是由时长决定。实测两种：

- 轻量链（15s）：**6~8 次碰撞**
- 密集链（25s）：**12 次以上**，且触发时间钉在音乐网格上

**最硬的一条**：每次碰撞的**撞击前必须严格为零**——撞击发生之前，
被撞的东西完全静止、不可见、不预动。一旦给「提前预备动作」，因果感就没了。

### 视觉语言

- 桌面/台面视角（略带俯视），实体有**接触阴影**——没有影子的物体会被判「像贴纸」
- 暖灰底 + 白色物体 + **一个红橙色的「因」**（第一个被推动的东西用强调色，其余中性）
- 高度从影子里读出来

### 核心手法

**contact（接触）**。挤压必须**成对出现**以符合体积守恒：撞上去时压扁纵向、同时鼓出横向，
`xz = 1/sqrt(y)`。只压不鼓会读成「图被拉变形了」。

### 承接方式

**上一次的撞击**。活下来的不是某个物体，是**动量**。

### 声学

每一次碰撞一次 foley，**同一个空间**。撞击的对齐很关键——
实测：许多近乎相同的撞击在时间上对齐会**变成音高**（听成一声嗡），
所以要么错开 ≥ 20ms，要么让它们**故意完全对齐**成一个音。

### 何时该用

- 要表达「连锁」「蔓延」「一个错误引发下游一切」——**失败链路、故障传播、依赖关系**
- 有明确物理直觉的概念
- 需要节奏感强的段落

### 何时别用

- 抽象/无实体的概念（数据流、权限、状态机）——硬做会假
- 需要展示文字为主的内容（碰撞会打断阅读）
- 时长很短（< 6s 时链来不及建立）

### 用裁云怎么落地

**这是裁云三维唯一真正值得用的模板之一**（另一个是模板 4）。实测成本：
4 个三维物体 **170ms/帧**，无三维 104ms/帧（+66ms）。物体少时几乎无感。

必守四条（全部来自实测）：

1. **`model_group` 共享世界**：同一组内的物体共相机/光照/坐标，才有正确遮挡与接触阴影。
2. **组首的 `model_tilt` 设 89°**：否则画框中心永远留一个 ~27px 黑块。
3. **成员 `y` 越大越靠前**（与源码注释相反，以实测为准）。要物体在某物**前面**就加大 `y`。
4. **`model_shadow` 别开太大**：阴影半径系数过大会读成「旁边一个黑椭圆」。0.20 是舒适值。

 "model_shape":"plane","model_scale":0.01,"model_tilt":89,

{"kind":"model3d","name":"dom0","model_group":"g",
 "x":380,"y":565,"w":240,"h":240,"model_shape":"box","model_scale":0.34,

碰撞用 `layout` 的 `dx/dy` 驱动成员在世界里真的平移（**这条通路本次修过**：
增量会经 `member_states` 传进组渲染器），撞击帧给 `scale` 挤压。
