# 单点身份

**一句定位**：零素材、零镜头，一个元素演完全片。解决「没有任何素材，怎么讲完整故事」。

### 节拍结构

12 段 / **无剪辑点**（同一个元素连续变形，全片没有一个「换掉了」）。实测：

| 时刻 | 它做什么 |
|---|---|
| 0.50s | 出现一个点（弹簧弹出） |
| 1.00–1.50s | 向左滑、拉长成竖线（光标） |
| 1.75–2.75s | 收缩、**裂成四个点 + 标签** |
| … | 每一段都从上一段的形态继续 |

**关键**：全片只有**一个主体**，它的身份始终连续。观众跟着「它变成了什么」看下去。

### 视觉语言

- 近黑底 + **唯一一个被照亮的**主体 + 暖白字
- 主体可以有发光（`glow` 图元），因为它是全片唯一的光源
- 字体：字标用有性格的字面，正文用无衬线

### 核心手法

**变形（morph）**。不是「点消失、卡片出现」，而是「点拉长、卷成卡的边框、
边框里长出内容」。这条是本模板的**全部**——一旦有一处是替换而非变形，整片就散了。

### 承接方式

**自身 morph**：边界上活下来的永远是那个元素本身。

### 声学

一个点每一次变形配一次**材质变化**的声音（点→线是拉伸音，线→面是展开音）。
同一空间。

### 何时该用

- **零素材**（没有截图、没有录像、没有图）
- 想讲「一个东西如何成为一切」——抽象概念、方法论、身份隐喻
- 需要极强的统一感

### 何时别用

- 有多项并列能力要报（本模板天然不适合列举）
- 需要展示真实界面细节
- 时长超过 ~20s（单元素会显单调，除非有强变形链）

### 用裁云怎么落地

**这是最能用满裁云的一个模板**——`layout` 脚本里对同一个图层连续改 `dw/dh/radius/rotate/alpha`。

```jsonc
{"kind":"custom","duration":5.0,"layers":[
  // 主体：一个 rect，靠 layout 让它从 8×8 圆点长成 600×360 圆角卡
  {"kind":"rect","name":"being","x":940,"y":520,"w":40,"h":40,
   "fill":"#7C6CFF","radius":20},
  // 光晕：跟着主体走，强度随主体尺寸衰减
  {"kind":"glow","name":"halo","x":740,"y":320,"w":440,"h":440,
   "fill":"#7C6CFF","intensity":0.55,"spread":1.0},
  // 文字在主体变形到「足够大」之后才出现（此时它才是卡的标题）
  {"kind":"text","name":"label","x":0,"y":0,"w":1200,"h":80,
   "text":"一次失败，留下结论","size":44,"color":"#EFECE6","align":1,"opacity":0}
]}
```

`layout` 关键：**变形必须是连续的**。用 `kLerp` 把「点」与「卡」两套参数插值，
中间任何一帧都不能出现「旧形态 fade out + 新形态 fade in」。

```
// 伪代码（真代码见示例工程）
const k = ease.out(seg(t, 1.2, 2.4));
dw = lerp(40, 600, k) - 40;      // 宽
dh = lerp(40, 360, k) - 40;      // 高
radius 由 layout 无法直接改 → 用「两层 rect 叠 + 交叉透明度」模拟圆角变化
```

> ⚠ **裁云的 `radius` 不能逐帧改**（不是 `LayerDelta` 字段）。
> 圆角变化要用「两层不同 radius 的 rect 叠着、交叉改 alpha」实现——
> 这是本模板在裁云上的唯一硬约束，写进示例工程的注释里了。
