# 在场操作

**一句定位**：一个角色（吉祥物、光标、手）的**身体**驱动每一个界面反应。
它落在图标上就是点击，它跳过输入行就是打字。

### 节拍结构

跟随角色的**一次任务**：进入 → 做几件事 → 遇到一个阻力（窗口的「不行」）→ 解决 → 落版。
实测（19s）：无剪辑，但相机在 4~5 个位置之间移动（桌面 → Dock → Mission Control）。

### 视觉语言

- 桌面/工作台视角，界面是**玻璃板**（有透射、有厚度感）
- 角色有实体（有影子、有重量），它压下去时界面要有**形变反馈**
- 相机低角度、贴桌面，靠**景深**区分前后

### 核心手法

**角色即指针**。这是全模板的唯一语法：**每一个**界面反应都必须能追溯到角色身体的一个动作。
不能出现「界面自己亮了」。

### 承接方式

**手即指针**：活下来的是角色本身。

### 声学

角色的动作声与界面反馈声**成对出现**（落=点击声、跳=轻弹），
且**同一次动作只有一个声音**（不要「落 + 点击 + 确认」三连）。

### 何时该用

- 产品有**拟人化形象/吉祥物**
- 想展示「谁在做这件事」（智能体、助手、自动化）
- 需要亲和力与幽默

### 何时别用

- 产品无形象（硬造一个会尴尬）
- 严肃/合规场景
- 需要展示大量文字内容

### 用裁云怎么落地

角色用 **`model3d`**（球/圆角盒最省）或二维 `ellipse` + 接触阴影。
界面用 `rect` 玻璃感（`fill` 半透明 + `fill_alt` 渐变 + `stroke` 亮边）。

```jsonc
{"kind":"model3d","name":"hero","model_group":"g",
 "x":860,"y":520,"w":200,"h":200,"model_shape":"sphere","model_scale":0.22,
 "model_shadow":0.3,"model_color":"#F5C24A","model_color_alt":"#7A5410",
 "model_spin":0,"model_tilt":0}
```

「落在图标上」= `hero` 的 `dx/dy` 移到图标位置 + 落地帧给 `scale` 压扁
（`dw`+8%/`dh`−8%，体积守恒）+ 图标同时 `scale` 轻微回弹（**两者必须同时**）。
