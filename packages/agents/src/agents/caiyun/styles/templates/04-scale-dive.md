# 尺度一镜

**一句定位**：一次连续运动穿越所有尺度，中间不剪断。观众不知道自己在哪一层，
只知道「一直在往下/往上」。

### 节拍结构

无剪辑点，全部由**相机位置**分段。实测（15s）：

| 段落 | 相机 |
|---|---|
| 起点 | 熟视的特写（3.6×） |
| 拉出 | 3.6× → 1.12×（五段缓动） |
| 平稳推进 | → 1.5×，带 **1.3° 侧倾**与手持浮动 |
| 冲击 | 冲到 **3×** 停在某一点 |
| 穿越 | 3× → 1× 继续 |
| 落定 | 完全静止 |

**关键**：相机**从不剪断**。它提前半拍跟着主体、抢在下一个东西落地前甩过去、
像手持一样轻微浮动、东西撞上来时跟着一震；该停时完全静止。

### 视觉语言

- 每一层用自己的**单位**（时间用表盘、数量用刻度、距离用标尺），因为跨尺度时观众靠单位定位
- 排印可以极大（大到只剩几个字母），因为尺度的对比就是内容
- 底色单一，靠**明度层级**区分层次

### 核心手法

**zoomThrough（穿层）**：这一层的某个元素，就是下一层的整幅画面。
不是「淡出上一层、淡入下一层」。

### 承接方式

**同一个主体**：船锚式跟随——相机追着屏幕上的锚点走，让锚点在 1× 与 300× 时落在同一位置。

### 声学

由**相机速度**驱动（不是由事件驱动）：速度越快，铺底越密；
穿过层次时给一次低频冲击。同一空间。

### 何时该用

- 要讲「同一件事在不同尺度上重复」——**分辨率、粒度、复利、递归**
- 有强烈的「一层套一层」结构
- 想做出「一镜到底」的高级感

### 何时别用

- 内容本身是并列的（没有层级关系）
- 需要观众读很多文字（跨尺度时文字必然有一段读不了）
- 时长很短：穿越至少需要 2~3 个层次才成立

### 用裁云怎么落地

裁云的相机是**逐场景**的（`cam_zoom_from/to` + `cam_anchor_x/y`），
所以「一镜穿越」要用**一个场景 + layout 脚本自算相机**，不要拆成多个场景。

```jsonc
{"kind":"custom","duration":6.0,
 "cam_zoom_from":1.0,"cam_zoom_to":1.0,   // 交给 layout 控制，这里只占位
 "layers":[
   // 每一"层"是一组图元，全部叠在同一场景里，靠相机缩放决定谁可见
   {"kind":"text","name":"L3","x":-1400,"y":420,"w":3000,"h":200,
    "text":"二十秒","size":150,"color":"#8FB6F5"},
   {"kind":"text","name":"L2","x":-200,"y":500,"w":1800,"h":120,
    "text":"一次研判","size":72,"color":"#C8D6EA"},
   {"kind":"text","name":"L1","x":760,"y":560,"w":600,"h":60,
    "text":"一行日志","size":30,"color":"#4E6480"}
 ]}
```

> ⚠ **`shapes`（layout 里 push 的脚本图元）不过相机**——推镜必须自己把坐标送进变换。
> 所以尺度一镜优先用**图层**（`layers` 数组）而不是 `shapes`。

`layout` 里给每层一个「可见窗口」：当 `zoom` 落在 [z0,z1] 之外时 alpha=0，
落在之内时按 `sstep` 淡入。淡入区间要**重叠**，否则会有真空帧。
