# 裁云 · 风格模板库（总纲）

> **这是什么**：七种「一部片子靠什么推进」的模板。选型在第一笔之前定下来——
> 选错模板，后面每一镜都在跟它打架。
>
> **怎么读**（按需，不要一次全读）：
> 1. 本文件——选型表 + 三条硬门槛 + 承接判据（**选型只需这一屏**）
> 2. `style_guide name=<模板>`——选中的那个模板的九个字段（定位/节拍/视觉/手法/
>    承接/声学/何时用/何时别用/**用裁云怎么落地**），写了具体图层与 layout 写法
> 3. 本文件后半（反模式 / 风格令牌 / 数字红线）写脚本前再对一遍
>
> 模板名：`01-capability-list` `02-single-point` `03-causal-chain` `04-scale-dive`
> `05-contrast-split` `06-spine` `07-pointer`
>
> 一镜示例工程在 `examples/caiyun/styles/<编号>-<名字>/`（只入库脚本）。

来源：本库归并自 13 部实测成片（externally published films，方法论层面），
每条的「实测数字」都来自那些片子的公开拆解文档。**不含任何外部源码**——
这里写的是**裁云的实现方式**。

## 〇、选型表（先看这张）

| # | 模板 | 一句话 | 第一判据：靠什么接住下一镜 |
|---|---|---|---|
| 1 | 能力清单 | 并列报出多项能力，每项一个物理 | 手/因果 + 硬切 |
| 2 | 单点身份 | 一个元素演化出全部画面 | 它自己变形 |
| 3 | 因果链 | 每次碰撞启动下一次 | 上一次的撞击 |
| 4 | 尺度一镜 | 一次连续运动穿越所有尺度 | 同一个主体 |
| 5 | 对照分裂 | 两态并置，最后揭示差异 | 比较 |
| 6 | 脊椎串联 | 一条主线产出多个产物 | 主线变形 |
| 7 | 在场操作 | 角色身体驱动每个界面反应 | 手即指针 |

### 选型硬门槛（三条，来自实测）

1. **必须有 rest**：全片**完全静止帧 ≥ 25%**，且至少一段**连续 ≥ 1.0s** 低于低速阈值。
   没有静止，所有动作都落不下来（见 §8「指标牵引」反模式）。
2. **爆点只准当一次主角**：一种强手法全片出现一次。重复即废——
   实测代价：同一手法用 8 次，观众读成「无端抖动」。
3. **承接必须写进节拍表**：每个边界都要写清「哪个元素活下来、它做了什么」。
   这是唯一能量出「像不像 PPT」的指标：**承接分 < 0.5 判不合格，< 0.7 警告**。

### 承接判据（怎么算「活下来了」）

边界 = **0.4s** 窗口内大部分画面换了身份。某元素算「承接」需满足：

- 位移 ≥ 画面对角线的 **2%**，或
- 缩放 ≥ **10%**，或
- 形状连续变形（圆角矩形变圆、矩形拉长成线）

**淡入/滑入不是承接**——它只是「上一镜消失、下一镜出现」的礼貌说法。

## 八、跨模板的反模式（实测代价）

| 反模式 | 为什么错 | 实测代价 |
|---|---|---|
| **均匀间隔** | 每镜一样长 = 节拍器，读成 PPT | 镜头长度 CV < 0.25 直接判 PPT |
| **淡入/滑入当承接** | 那是「换掉了」的礼貌说法 | 承接分 0.00 被否（节奏满分也没用） |
| **标注补救含义** | 图形没说清的事，加字只会更糊 | 加标注后反馈「更看不懂了」 |
| **指标牵引设计** | 为压某个数而加动效，读起来是「莫名地动」 | 静止占比 82%→28%，但被判「莫名地动」 |
| **慢推当休息** | 慢推不是静止，眼睛一直在追 | 静止占比 0.178 是假的，真静止后 0.294 |
| **一种手法重复** | 第二次就不是「主角」了 | 同一手法 8 次 → 读成「无端抖动」 |
| **相机每拍重新构图** | 眼睛被迫反复找画面 | 2s 内换 5 次构图 = 另一种节拍器 |
| **三维文字不看角度** | 平印在斜面上的字，屏上高度 = 高度 × sin(仰角) | 9mm 关键词落地只剩 ~15px 且压扁一半 |

### 裁云特有的三个静默失效面

1. **`opacity: 0` 的图层无法被脚本点亮**——`alpha` 是乘数，0×任何=0。
   要「由脚本淡入」就把 `opacity` 写成 1，用 `alpha` 控制。
2. **`line` 的 `w`/`h` 是终点增量**，不是宽高。画折线必须给 `dh`。
3. **`layout` 字符串是文件路径**，不是源码。内联要写 `{"source": "..."}`。
   写错不报错——脚本静默不启用，画面只剩背景。

## 十、一页速查

**开工前必答四问**

1. 这一镜靠什么推进？（→ 定模板）
2. 每个边界上，**哪个元素活下来、它做了什么**？（→ 承接）
3. 全片哪里**完全静止**？至少一处 ≥ 1.0s。
4. 哪一种手法**只当一次主角**？

**数字红线**

| 项 | 值 |
|---|---|
| 完全静止帧占比 | ≥ 25%（裁云实测舒适区 20~35%） |
| 最长连续静止 | ≥ 1.0s |
| 镜头长度离散度 CV | ≥ 0.25 |
| 最长/最短镜 | ≥ 4× |
| 承接分 | ≥ 0.5（< 0.7 警告） |
| 承接位移 | ≥ 对角 2%，或缩放 ≥ 10% |
| burst 数 | 1 个（1.5s 内 ≥ 3 次大变化） |
| 字标落定后静止 | ≥ 1.0s |
| 批量动效收尾静止 | ≥ 0.5s |
| 三维开销 | +66ms/帧（4 物体，1080p） |
| 音效 gain（若加） | ≤ 0.25，且低于同时刻旁白 6dB |

**最易违反的三条**

1. 给每一镜都做了入场动画（→ 没有静止）
2. 用淡入代替承接（→ 承接分 0）
3. 为压指标加动效（→ 莫名地动）
